HackBook

About

A comprehensive cybersecurity knowledge base for CTF players and security researchers. Each topic includes detailed notes, hands-on labs, and practice CTF challenges.

Sections

Binary Exploitation

ELF internals, stack overflows, format strings, ROP chains, GOT/PLT hijacking, heap exploitation, and shellcode development.

  • Fundamentals — ELF format, memory layout, protections, GDB, pwntools
  • Stack Overflow — Buffer overflows, offset discovery, ret2win, canary bypass
  • Format Strings — Stack leaks, arbitrary read/write, GOT overwrite via printf
  • ROP — Return-oriented programming, ret2libc, mprotect, SROP, stack pivots
  • GOT/PLT Hijacking — Dynamic linking exploitation, libc leaks, ret2plt
  • Heap Exploitation — ptmalloc2 internals, tcache poison, UAF, double free
  • Shellcode — Writing shellcode, encoding, NOP sleds, size optimization

Networking

Protocol fundamentals, scanning, packet analysis, and network-level attacks.

  • TCP/IP — Protocol stack, 3-way handshake, sockets, netcat
  • DNS — Record types, zone transfers, tunneling, enumeration
  • Network Scanning — Nmap, masscan, service enumeration, recon methodology
  • ARP & Layer 2 — ARP spoofing, MITM, MAC flooding, VLAN hopping
  • DHCP — DORA process, starvation, rogue servers
  • Wireshark — Packet analysis, display filters, pcap forensics

Architecture

Low-level x86 architecture, assembly programming, and memory management.

  • x86 Assembly — Registers, instructions, calling conventions, syscalls
  • x86 OS Internals — Operating system architecture
  • x86 Firmware — BIOS, UEFI, firmware security
  • Memory Management — Virtual memory, ASLR, mmap, protections

Web

Web application security, injection attacks, and authentication exploits.

  • HTTP — Protocol fundamentals, headers, CORS, cookies, request smuggling, caching attacks
  • XSS — Reflected, stored, DOM-based, filter bypass, CSP evasion
  • SQL Injection — UNION, blind, time-based, sqlmap, NoSQL injection
  • SSRF — Internal service access, cloud metadata, filter bypass
  • Auth Attacks — JWT, OAuth, session management, IDOR
  • Burp Suite — Proxy, repeater, intruder, extensions

Blockchain

Smart contract security, Solidity vulnerabilities, and DeFi exploit patterns.

  • Solidity — Language fundamentals, ERC standards, development tools
  • Smart Contract Vulns — Reentrancy, overflow, access control, oracle manipulation
  • DeFi Attacks — Flash loans, price manipulation, sandwich attacks

Windows

Complete Windows security expertise: internals, authentication, kernel security, Active Directory, offensive techniques, and hardening.

  • Internals — Processes (EPROCESS/KPROCESS/PEB), tokens, DLL loading, syscalls, mitigations
  • Authentication — NTLM, Kerberos deep dive, LSA/LSASS, access tokens, SIDs, ACLs/DACLs/SACLs
  • Kernel Security — PatchGuard, VBS/HVCI, driver signing, BYOVD, Secure Boot, kernel mitigations
  • OS Security Mechanisms — Defender/AMSI, AppLocker, WDAC, BitLocker/TPM, ETW, Sysmon
  • Active Directory — Kerberos attacks, ADCS, delegation, ACL abuse, DCSync, BloodHound
  • PowerShell Security — AMSI bypass, CLM escape, logging, JEA, WinRM, offensive PS
  • Offensive / Red Team — Process injection, LOLBAS, UAC bypass, COM/DCOM, WMI, token manipulation
  • Networking & Protocols — SMB relay, RPC/DCOM, LDAP, DNS poisoning, auth coercion
  • Privilege Escalation — Service misconfig, Potato family, DLL hijacking, kernel exploits
  • Lateral Movement — PtH, PtT, WinRM, pivoting (chisel/ligolo), C2 frameworks
  • Forensics & IR — Memory/disk forensics, event logs, timeline, registry, KAPE/Volatility
  • Hardening — CIS benchmarks, GPO, ASR rules, Credential Guard, tiered admin, ADCS

Cryptography

Classical and modern cryptography, from Caesar ciphers to RSA attacks and PRNG exploitation.

  • Classical Ciphers — Caesar, Vigenère, substitution, transposition, XOR
  • Symmetric Crypto — AES modes, padding oracle, ECB/CBC/CTR attacks
  • Asymmetric Crypto — RSA attacks, Diffie-Hellman, ECC, ECDSA nonce reuse
  • Hashing — Hash cracking, length extension, HMAC, birthday attacks
  • Crypto Attacks — PRNG prediction, Mersenne Twister, timing attacks, Z3

Reverse Engineering

Binary analysis, debugging, anti-reversing bypass, and malware analysis.

  • Static Analysis — Ghidra, IDA, radare2, Angr, binary patching
  • Dynamic Analysis — GDB scripting, Frida hooking, unicorn emulation, fuzzing

JavaScript engine internals, V8 exploitation, and browser sandbox escape.

Digital forensics, memory analysis, and steganography for CTF competitions.
