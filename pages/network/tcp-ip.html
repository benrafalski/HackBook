TCP/IP Fundamentals

OSI Model vs TCP/IP Model

The OSI model is a theoretical 7-layer framework. TCP/IP is the practical 4-layer model the internet actually runs on.

OSI Layer # TCP/IP Layer Protocols Data Unit
Application7 Application HTTP, FTP, SSH, DNS, SMTP, SNMP Data
Presentation6
Session5
Transport4 Transport TCP, UDP Segment / Datagram
Network3 Internet IP, ICMP, ARP Packet
Data Link2 Network Access Ethernet, Wi-Fi, PPP Frame
Physical1Bits

Key takeaway: When crafting packets (scapy, raw sockets), you work at layers 3-4. When doing web exploitation, you're at layer 7. Understanding encapsulation (data → segment → packet → frame) is critical for packet analysis.

TTL (Time to Live)

  • Default TTL by OS: Linux = 64, Windows = 128, Cisco = 255
  • Used by traceroute — sends packets with incrementing TTL to map hops
  • TTL in ping replies can fingerprint the target OS

IP Fragmentation

  • Packets larger than the MTU (typically 1500 bytes) get fragmented
  • Reassembled at the destination, not at intermediate routers
  • Exploit angle: Overlapping fragments can bypass firewalls/IDS (Teardrop attack, fragment overlap attacks)
  • DF flag set = router drops packet and sends ICMP "Fragmentation Needed" (used in Path MTU Discovery)

TCP (Transmission Control Protocol)

3-Way Handshake

# The foundation of every TCP connection
Client → Server:  SYN         (seq=x)
Server → Client:  SYN-ACK     (seq=y, ack=x+1)
Client → Server:  ACK         (seq=x+1, ack=y+1)

# Connection teardown (4-way):
Client → Server:  FIN
Server → Client:  ACK
Server → Client:  FIN
Client → Server:  ACK

FieldSizeDescription
Source Port16 bitsSender port (0-65535)
Destination Port16 bitsReceiver port
Sequence Number32 bitsByte position in stream
Acknowledgment Number32 bitsNext expected byte from sender
Data Offset4 bitsHeader length in 32-bit words
Flags6 bitsSYN, ACK, FIN, RST, PSH, URG

Sequence Numbers & Window Size

  • Sequence number: Tracks byte position in the stream. ISN (Initial Sequence Number) is randomly chosen during handshake.
  • If ISN is predictable → TCP session hijacking is possible (blind spoofing)
  • Window size: Advertises how many bytes the receiver can buffer. Window size 0 = "stop sending" (flow control).
  • Window scaling: TCP option that multiplies window size for high-bandwidth connections

UDP (User Datagram Protocol)

Characteristics

  • Connectionless — no handshake, no guaranteed delivery, no ordering
  • Fast — minimal overhead (8-byte header vs TCP's 20+ bytes)
  • No state — harder to scan (no RST for closed ports, ICMP unreachable instead)

UDP Header (8 bytes)

FieldSizeDescription
Source Port16 bitsSender port
Destination Port16 bitsReceiver port
Length16 bitsHeader + data length
Checksum16 bitsOptional in IPv4, mandatory in IPv6

When UDP is Used

  • DNS (port 53) — quick lookups, falls back to TCP for large responses
  • DHCP (ports 67/68) — client doesn't have an IP yet, can't do TCP
  • SNMP (port 161) — network monitoring
  • TFTP (port 69) — simple file transfer (no auth!)
  • VoIP/RTP, video streaming, gaming — latency-sensitive

ICMP (Internet Control Message Protocol)

ICMP rides on top of IP (protocol number 1) but is considered a network-layer protocol. Not used for data transfer — it's for diagnostics and error reporting.

TCP Session Hijacking

  • Concept: Attacker injects packets into an active TCP session by predicting/sniffing sequence numbers
  • Requirements: Must know src/dst IP, src/dst port, and current sequence numbers
  • Blind hijacking: Attacker can't see traffic — must predict ISN (hard with modern randomized ISNs)
  • On-path hijacking: Attacker can sniff traffic (ARP spoofing, MITM) — trivial to get seq numbers
  • Tools: ettercap, bettercap, scapy
# Scapy: Inject a RST to kill a connection (requires sniffed seq/ack)
from scapy.all import *

ip = IP(src="victim_ip", dst="server_ip")
tcp = TCP(sport=victim_port, dport=80, flags="R", seq=sniffed_seq)
send(ip/tcp)

IP Spoofing

  • Concept: Forging the source IP in packet headers
  • Easy with UDP/ICMP (connectionless — no handshake to complete)
  • Hard with TCP — you need to complete the 3-way handshake, which requires seeing the SYN-ACK (sent to the spoofed IP)
  • Use cases: DDoS amplification, bypassing IP-based ACLs, DNS spoofing
  • Defense: Ingress/egress filtering (BCP38), SYN cookies, randomized ISNs
# Scapy: Send a spoofed ping
from scapy.all import *

pkt = IP(src="1.2.3.4", dst="target.com") / ICMP()
send(pkt)

Lab 4: TCP 3-Way Handshake & SYN Scan with Scapy

Medium

Objective: Manually perform a TCP 3-way handshake using scapy, then implement a SYN scan (half-open scan) like nmap -sS.

Manual 3-Way Handshake
from scapy.all import *

target = "target.com"
dport = 80

# Step 1: SYN
ip = IP(dst=target)
syn = TCP(sport=RandShort(), dport=dport, flags="S", seq=100)
syn_ack = sr1(ip/syn, timeout=3)

if syn_ack and syn_ack[TCP].flags == "SA":
    print(f"[+] SYN-ACK received! Server seq={syn_ack[TCP].seq}")

    # Step 2: ACK (complete the handshake)
    ack = TCP(
        sport=syn.sport,
        dport=dport,
        flags="A",
        seq=syn_ack[TCP].ack,
        ack=syn_ack[TCP].seq + 1
    )
    send(ip/ack)
    print("[+] Handshake complete!")

    # Step 3: Send HTTP request over the connection
    payload = "GET / HTTP/1.1\r\nHost: {}\r\n\r\n".format(target)
    psh = TCP(
        sport=syn.sport,
        dport=dport,
        flags="PA",
        seq=syn_ack[TCP].ack,
        ack=syn_ack[TCP].seq + 1
    )
    resp = sr1(ip/psh/payload, timeout=3)
    if resp and resp.haslayer(Raw):
        print(resp[Raw].load.decode(errors="ignore")[:500])

    # Clean up: send RST
    rst = TCP(sport=syn.sport, dport=dport, flags="R", seq=syn_ack[TCP].ack + len(payload))
    send(ip/rst)
else:
    print("[-] No SYN-ACK received")
SYN Scanner
from scapy.all import *
import sys

def syn_scan(target, ports):
    """
    SYN scan (half-open): Send SYN, check for SYN-ACK.
    Never completes the handshake — sends RST instead.
    This is what nmap -sS does.
    """
    print(f"[*] SYN scanning {target}")
    open_ports = []

    for port in ports:
        syn = IP(dst=target) / TCP(sport=RandShort(), dport=port, flags="S")
        resp = sr1(syn, timeout=1, verbose=0)

        if resp is None:
            status = "Filtered"
        elif resp.haslayer(TCP):
            if resp[TCP].flags == 0x12:  # SYN-ACK
                open_ports.append(port)
                status = "Open"
                # Send RST to close (don't complete handshake)
                rst = IP(dst=target) / TCP(sport=syn[TCP].sport, dport=port, flags="R")
                send(rst, verbose=0)
            elif resp[TCP].flags == 0x14:  # RST-ACK
                status = "Closed"
            else:
                status = f"Unknown flags: {resp[TCP].flags}"
        else:
            status = "Filtered"

        if status != "Closed":
            print(f"  Port {port}: {status}")

    print(f"\n[+] Open ports: {open_ports}")
    return open_ports

# Scan common ports
ports = [21, 22, 25, 53, 80, 110, 135, 139, 443, 445, 3306, 3389, 8080]
syn_scan("target.com", ports)

Lab 6: ICMP Ping Implementation

Medium

Objective: Implement ICMP echo request/reply from scratch using raw sockets. Calculate the checksum manually.

import socket
import struct
import os
import time

def checksum(data):
    if len(data) % 2:
        data += b'\x00'
    s = sum(struct.unpack('!%dH' % (len(data) // 2), data))
    s = (s >> 16) + (s & 0xffff)
    s += s >> 16
    return ~s & 0xffff

def ping(dest, count=4):
    sock = socket.socket(socket.AF_INET, socket.SOCK_RAW, socket.IPPROTO_ICMP)
    sock.settimeout(2)
    dest_ip = socket.gethostbyname(dest)

    for seq in range(count):
        # ICMP Echo Request: type=8, code=0
        pid = os.getpid() & 0xFFFF
        header = struct.pack('!BBHHH', 8, 0, 0, pid, seq)
        payload = struct.pack('!d', time.time())
        chk = checksum(header + payload)
        header = struct.pack('!BBHHH', 8, 0, chk, pid, seq)

        sock.sendto(header + payload, (dest_ip, 0))
        try:
            data, addr = sock.recvfrom(1024)
            icmp_header = data[20:28]
            rtype, code, _, r_id, r_seq = struct.unpack('!BBHHH', icmp_header)
            send_time = struct.unpack('!d', data[28:36])[0]
            rtt = (time.time() - send_time) * 1000
            print(f"Reply from {addr[0]}: seq={r_seq} time={rtt:.1f}ms")
        except socket.timeout:
            print(f"Request timed out (seq={seq})")
    sock.close()

ping("8.8.8.8")

Lab 7: TCP State Machine Tracker

Medium

Objective: Sniff TCP traffic and track connection states (SYN_SENT → ESTABLISHED → FIN_WAIT, etc.) in real time.

from scapy.all import *
from collections import defaultdict

connections = defaultdict(lambda: "CLOSED")

def track_state(pkt):
    if not pkt.haslayer(TCP):
        return
    src = f"{pkt[IP].src}:{pkt[TCP].sport}"
    dst = f"{pkt[IP].dst}:{pkt[TCP].dport}"
    key = tuple(sorted([src, dst]))
    flags = pkt[TCP].flags

    old = connections[key]
    if flags == "S":
        connections[key] = "SYN_SENT"
    elif flags == "SA":
        connections[key] = "SYN_RECEIVED"
    elif flags == "A" and old == "SYN_RECEIVED":
        connections[key] = "ESTABLISHED"
    elif "F" in str(flags):
        if old == "ESTABLISHED":
            connections[key] = "FIN_WAIT_1"
        elif old == "FIN_WAIT_1":
            connections[key] = "TIME_WAIT"
    elif "R" in str(flags):
        connections[key] = "CLOSED"

    if connections[key] != old:
        print(f"[{key[0]} ↔ {key[1]}] {old} → {connections[key]}  [{flags}]")

print("[*] Tracking TCP states... (Ctrl+C to stop)")
sniff(filter="tcp", prn=track_state, store=0)

from scapy.all import *

def traceroute_custom(target, max_hops=30):
    target_ip = socket.gethostbyname(target)
    print(f"Traceroute to {target} ({target_ip}), max {max_hops} hops\n")

    for ttl in range(1, max_hops + 1):
        pkt = IP(dst=target_ip, ttl=ttl) / ICMP()
        reply = sr1(pkt, timeout=2, verbose=0)

        if reply is None:
            print(f"{ttl:3d}  * * * (no response)")
        elif reply[ICMP].type == 11:  # Time Exceeded
            try:
                hostname = socket.gethostbyaddr(reply[IP].src)[0]
            except socket.herror:
                hostname = reply[IP].src
            rtt = (reply.time - pkt.sent_time) * 1000
            print(f"{ttl:3d}  {hostname} ({reply[IP].src})  {rtt:.1f} ms")
        elif reply[ICMP].type == 0:   # Echo Reply — destination reached
            rtt = (reply.time - pkt.sent_time) * 1000
            print(f"{ttl:3d}  {target_ip}  {rtt:.1f} ms  *** Destination reached ***")
            break

Challenge 3: Recon Ranger

Hard

Given a target IP, build a port scanner that identifies all open TCP ports (1-10000), performs banner grabbing, and identifies the service running on each open port. The flag is hidden in one of the service banners, but only appears if you connect with the correct User-Agent header.

Solution
import socket
import threading
import re
from queue import Queue

target = "challenge.ctf.com"
open_ports = []
lock = threading.Lock()
q = Queue()

def scan_port(port):
    """TCP connect scan on a single port."""
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(1)
        result = s.connect_ex((target, port))
        if result == 0:
            with lock:
                open_ports.append(port)
        s.close()
    except Exception:
        pass

def worker():
    while not q.empty():
        port = q.get()
        scan_port(port)
        q.task_done()

# Phase 1: Port scan with 100 threads
print(f"[*] Scanning {target} ports 1-10000...")
for port in range(1, 10001):
    q.put(port)

threads = []
for _ in range(100):
    t = threading.Thread(target=worker, daemon=True)
    t.start()
    threads.append(t)

q.join()
open_ports.sort()
print(f"[+] Open ports: {open_ports}")

# Phase 2: Banner grabbing
def grab_banner(port):
    """Connect and grab the banner, trying multiple probes."""
    banners = []
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(3)
        s.connect((target, port))

        # Try receiving a banner immediately (SSH, FTP, SMTP)
        try:
            banner = s.recv(4096).decode(errors="ignore").strip()
            if banner:
                banners.append(banner)
        except socket.timeout:
            pass

        # Try HTTP probe with custom User-Agent
        http_req = (
            f"GET / HTTP/1.1\r\n"
            f"Host: {target}\r\n"
            f"User-Agent: CTF-Scanner/1.0\r\n"
            f"\r\n"
        )
        s.send(http_req.encode())
        try:
            resp = s.recv(4096).decode(errors="ignore")
            if resp:
                banners.append(resp)
        except socket.timeout:
            pass

        s.close()
    except Exception as e:
        banners.append(f"Error: {e}")

    return "\n".join(banners)

print("\n[*] Grabbing banners...")
for port in open_ports:

print("\n[+] Scan complete.")
