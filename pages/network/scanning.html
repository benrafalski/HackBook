Network Scanning

Nmap Fundamentals

Nmap (Network Mapper) is the de facto standard for network discovery and security auditing. Root/sudo is required for raw socket scans (SYN, UDP, OS detection).

Basic Syntax

nmap [scan type] [options] [target]

# Target formats
nmap 192.168.1.1              # single host
nmap 192.168.1.0/24           # CIDR subnet
nmap 192.168.1.1-254          # range
nmap -iL targets.txt          # from file
nmap 192.168.1.1 --exclude 192.168.1.5

Port States

StateMeaning
openApplication actively accepting connections
closedPort reachable but no application listening (responds with RST)
filteredPacket dropped by firewall — no response or ICMP unreachable
unfilteredPort accessible but can't determine open/closed (ACK scan only)
open|filteredNo response — could be open or filtered (UDP, IP protocol scans)
closed|filteredCan't determine if closed or filtered (IP ID idle scan only)

Scan Types

TCP SYN Scan (Half-Open) — Default

Sends SYN, waits for SYN/ACK (open) or RST (closed). Never completes the handshake → stealthier. Requires root.

sudo nmap -sS 10.10.10.1

TCP Connect Scan

Full TCP handshake via connect() syscall. No root needed but slower and logged by target.

nmap -sT 10.10.10.1

UDP Scan

Sends UDP packets. Open ports rarely respond; closed ports return ICMP port unreachable. Very slow — use with specific ports.

sudo nmap -sU 10.10.10.1
sudo nmap -sU -p 53,161,500 10.10.10.1     # target specific UDP ports
sudo nmap -sU -sS 10.10.10.1               # combined TCP SYN + UDP

Service/Version Detection

Probes open ports to determine service name, version, and extra info. Sends application-layer probes.

nmap -sV 10.10.10.1
nmap -sV --version-intensity 5 10.10.10.1   # 0 (light) to 9 (all probes)

Default Scripts + Version Detection

nmap -sC 10.10.10.1          # runs default NSE scripts
nmap -A 10.10.10.1           # aggressive: -sV -sC -O --traceroute

OS Detection

sudo nmap -O 10.10.10.1
sudo nmap -O --osscan-guess 10.10.10.1    # force best guess

Other Scan Types

FlagScanUse
-sAACK scanMap firewall rules (filtered vs unfiltered)
-sNNull scanNo flags set — evade non-stateful firewalls
-sFFIN scanOnly FIN flag — bypass simple packet filters
-sXXmas scanFIN+PSH+URG — same evasion use as null/FIN
-sWWindow scanLike ACK but examines TCP window size
-sI zombieIdle scanCompletely blind scan via zombie host

Host Discovery

# Ping sweep — find live hosts (no port scan)
nmap -sn 10.10.10.0/24

# Skip discovery — scan even if host appears down
nmap -Pn 10.10.10.1

# TCP SYN ping on specific ports
nmap -PS22,80,443 10.10.10.1

# TCP ACK ping
nmap -PA80,443 10.10.10.1

# UDP ping
nmap -PU53,161 10.10.10.1

# ICMP echo + timestamp + netmask
nmap -PE -PP -PM 10.10.10.0/24

# ARP discovery (LAN only, very reliable)
nmap -PR 192.168.1.0/24

# Stealthy engagement

Port Specification

nmap -p 80 10.10.10.1              # single port
nmap -p 80,443,8080 10.10.10.1     # multiple ports
nmap -p 1-1000 10.10.10.1          # range
nmap -p- 10.10.10.1                # all 65535 ports
nmap --top-ports 100 10.10.10.1    # top 100 most common
nmap -p U:53,161,T:80,443 10.10.10.1  # specify protocol

Output Formats

nmap -oN scan.txt 10.10.10.1      # normal (human-readable)
nmap -oX scan.xml 10.10.10.1      # XML (for tools like searchsploit)
nmap -oG scan.gnmap 10.10.10.1    # grepable (one host per line)
nmap -oA scan_all 10.10.10.1      # all three formats at once

-oA is the best default — generates .nmap, .xml, and .gnmap simultaneously.

Firewall / IDS Evasion

# Fragment packets (split into 8-byte fragments)
sudo nmap -f 10.10.10.1

# Custom MTU (must be multiple of 8)
sudo nmap --mtu 24 10.10.10.1

# Decoy scan — mix your IP with decoys
sudo nmap -D RND:5 10.10.10.1                    # 5 random decoys
sudo nmap -D 10.10.10.50,10.10.10.51,ME 10.10.10.1   # specific decoys

# Spoof source port (some firewalls allow port 53/80)
sudo nmap --source-port 53 10.10.10.1
sudo nmap -g 80 10.10.10.1                       # -g is shorthand

# Append random data to packets
sudo nmap --data-length 25 10.10.10.1

# Spoof MAC address
sudo nmap --spoof-mac 0 10.10.10.1               # random MAC
sudo nmap --spoof-mac Dell 10.10.10.1             # vendor prefix

# Use specific scan types to bypass stateless firewalls
sudo nmap -sN 10.10.10.1    # NULL — no flags
sudo nmap -sF 10.10.10.1    # FIN only
sudo nmap -sX 10.10.10.1    # Xmas — FIN+PSH+URG

# Combine techniques
sudo nmap -f --data-length 50 -D RND:3 -g 53 -T2 -sS 10.10.10.1

Masscan

Masscan is the fastest port scanner — can scan the entire internet in minutes. Uses its own TCP stack (bypasses OS kernel). Great for initial wide sweeps, then follow up with nmap for details.

# Basic scan — rate is packets per second
sudo masscan 10.10.10.0/24 -p 80,443 --rate=1000

# Scan all ports on a subnet
sudo masscan 10.10.10.0/24 -p 0-65535 --rate=10000

# Output to file (use with nmap for service detection)
sudo masscan 10.10.10.0/24 -p 0-65535 --rate=5000 -oL masscan_results.txt

# Convert masscan output → nmap target list
cat masscan_results.txt | grep open | awk '{print $4}' | sort -u > targets.txt
nmap -sV -sC -iL targets.txt

RustScan

Fast port scanner written in Rust. Scans ports then automatically pipes results to nmap for service detection.

# Basic scan — finds open ports, then runs nmap
rustscan -a 10.10.10.1

# Specify ports
rustscan -a 10.10.10.1 -p 80,443

# All ports with custom nmap flags
rustscan -a 10.10.10.1 -r 1-65535 -- -sV -sC

# Adjust batch size (concurrent connections)
rustscan -a 10.10.10.1 -b 1000

# Multiple targets
rustscan -a 10.10.10.1,10.10.10.2,10.10.10.3

#!/bin/bash
# recon.sh — Full automated recon pipeline
# Usage: ./recon.sh <target_ip>

    echo "[*] Phase 6: SMB enumeration"
    enum4linux -a $IP > $OUTDIR/enum4linux.txt 2>/dev/null
fi

echo "[+] Recon complete. Results in $OUTDIR/"

import socket

def grab_banner(host, port, probe=b""):

        s = socket.socket()
        s.settimeout(3)

Lab 7: Custom NSE Script Writing

Hard

Objective: Write a custom Nmap Scripting Engine (NSE) script to detect a specific service or vulnerability.

# NSE script: detect if an HTTP server has directory listing enabled
cat > /usr/share/nmap/scripts/http-dirlist-check.nse << 'EOF'
local http = require "http"
local shortport = require "shortport"
local stdnse = require "stdnse"

description = [[Checks if HTTP directory listing is enabled.]]
author = "HackBook"
license = "Same as Nmap--See https://nmap.org/book/man-legal.html"
categories = {"discovery", "safe"}

portrule = shortport.http

action = function(host, port)
  local paths = {"/", "/images/", "/uploads/", "/backup/", "/css/"}
  local results = {}

  for _, path in ipairs(paths) do
    local resp = http.get(host, port, path)
    if resp and resp.status == 200 then
      if resp.body and resp.body:match("Index of") then
        table.insert(results, path .. " - Directory listing ENABLED")
      end
    end
  end

  if #results > 0 then
    return stdnse.format_output(true, results)
  end
end
EOF

# Update script database and run
nmap --script-updatedb
nmap --script=http-dirlist-check -p 80 $IP

#!/bin/bash
# vuln_scan.sh — automated vulnerability pipeline

done

nmap --script=ftp-anon,ssh-auth-methods,http-default-accounts -p $PORTS $IP

            if probe:
                s.send(probe)
            banner = s.recv(4096).decode(errors="ignore").strip()
            s.close()
            if banner:
                with lock:
                    results[port] = {"probe": probe_name, "banner": banner[:500]}
                return
        except:
            pass

def worker():
    while not q.empty():
        grab(q.get())
        q.task_done()

for p in ports:
    q.put(p)
for _ in range(50):
    threading.Thread(target=worker, daemon=True).start()
q.join()

for port in sorted(results):
    print(f"[{port}] {results[port]['banner'][:100]}")
print(json.dumps(results, indent=2))

Lab 12: Scan Result Parsing with Python

Easy

Objective: Parse nmap XML output programmatically to extract hosts, ports, services, and generate structured reports.

# Generate XML output
nmap -sV -sC -p- $IP -oX scan_results.xml
#!/usr/bin/env python3
import xml.etree.ElementTree as ET
import json
import sys

tree = ET.parse(sys.argv[1] if len(sys.argv) > 1 else "scan_results.xml")
root = tree.getroot()

report = []
for host in root.findall("host"):
    ip = host.find("address").get("addr")
    entry = {"ip": ip, "ports": []}

    os_match = host.find(".//osmatch")
    if os_match is not None:
        entry["os"] = os_match.get("name")

    for port in host.findall(".//port"):
        state = port.find("state").get("state")
        if state == "open":
            svc = port.find("service")
            port_info = {
                "port": int(port.get("portid")),
                "protocol": port.get("protocol"),
                "service": svc.get("name", "unknown") if svc is not None else "unknown",
                "version": svc.get("product", "") + " " + svc.get("version", "") if svc is not None else "",
            }
            entry["ports"].append(port_info)
    report.append(entry)

# Output as JSON
print(json.dumps(report, indent=2))

# Summary
for host in report:
    print(f"\n{host['ip']} ({host.get('os', 'unknown OS')})")
    for p in host["ports"]:
        print(f"  {p['port']}/{p['protocol']}  {p['service']}  {p['version']}")

Challenge 7: Custom NSE Challenge

Hard

A custom service on port 7777 implements a challenge-response protocol. Write an NSE script that automatically solves the challenge and retrieves the flag. The protocol: server sends a hex-encoded number, you must respond with its SHA256 hash.

cat > solve_challenge.nse << 'NSEOF'
local nmap = require "nmap"
local shortport = require "shortport"
local openssl = require "openssl"

description = [[Solve the custom challenge-response on port 7777]]
portrule = shortport.port_or_service(7777, "challenge")

action = function(host, port)
  local socket = nmap.new_socket()
  socket:connect(host, port)
  local status, challenge = socket:receive_lines(1)
  if not status then return "Failed to receive challenge" end

  -- SHA256 hash the challenge
  local hash = openssl.digest("sha256", challenge)
  socket:send(hash .. "\n")

  local status, response = socket:receive_lines(1)
  socket:close()
  return response  -- should contain the flag
end
NSEOF

nmap --script=solve_challenge.nse -p 7777 $IP

The challenge value changes each connection. Your NSE script must: (1) connect, (2) read the challenge string, (3) compute SHA256 of the raw string (not hex-decoded), (4) send the hash back as lowercase hex. The flag comes in the next response line.
