Extended Euclidean Algorithm

def extended_gcd(a, b):
    if a == 0:
        return b, 0, 1
    gcd_val, x1, y1 = extended_gcd(b % a, a)
    x = y1 - (b // a) * x1
    y = x1
    return gcd_val, x, y

def modinv(e, phi):
    g, x, _ = extended_gcd(e % phi, phi)
    if g != 1:
        raise Exception("No modular inverse")
    return x % phi

# Or simply:
d = pow(e, -1, phi)        # Python 3.8+
d = gmpy2.invert(e, phi)   # gmpy2

Common Modulus Attack

Same message encrypted with same n but different e₁, e₂ where gcd(e1, e2) = 1.

import gmpy2

def common_modulus(n, e1, e2, c1, c2):
    g, a, b = gmpy2.gcdext(e1, e2)
    # a*e1 + b*e2 = 1
    if a < 0:
        c1 = gmpy2.invert(c1, n)
        a = -a
    if b < 0:
        c2 = gmpy2.invert(c2, n)
        b = -b
    m = (pow(c1, a, n) * pow(c2, b, n)) % n
    return m

Wiener's Attack (Small d)

When d < n^0.25 / 3, the continued fraction expansion of e/n reveals d.

def wiener_attack(e, n):
    # Compute continued fraction expansion of e/n
    cf = continued_fraction(e, n)
    convergents = get_convergents(cf)

    for k, d in convergents:
        if k == 0:
            continue
        # Check if phi = (e*d - 1) / k is valid
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        # phi = n - p - q + 1, so p + q = n - phi + 1
        s = n - phi + 1
        # p and q are roots of x^2 - s*x + n = 0
        disc = s * s - 4 * n
        if disc < 0:
            continue
        t = gmpy2.isqrt(disc)
        if t * t == disc:
            return d
    return None

def continued_fraction(num, den):
    cf = []
    while den:
        q = num // den
        cf.append(q)
        num, den = den, num - q * den
    return cf

def get_convergents(cf):
    convergents = []
    h_prev, h_curr = 0, 1
    k_prev, k_curr = 1, 0
    for a in cf:
        h_prev, h_curr = h_curr, a * h_curr + h_prev
        k_prev, k_curr = k_curr, a * k_curr + k_prev
        convergents.append((h_curr, k_curr))
    return convergents

Fermat Factorization (Close p and q)

If |p - q| is small, n can be factored quickly.

import gmpy2

def fermat_factor(n):
    a = gmpy2.isqrt(n) + 1
    b2 = a * a - n
    while not gmpy2.is_square(b2):
        a += 1
        b2 = a * a - n
    b = gmpy2.isqrt(b2)
    return int(a - b), int(a + b)

Hastad's Broadcast Attack

Same message sent to e recipients with different moduli. Use CRT to recover m^e, then take e-th root.

import gmpy2
from functools import reduce

def hastad_broadcast(ciphertexts, moduli, e):
    # CRT to find m^e mod (n1*n2*...*ne)
    N = reduce(lambda a, b: a * b, moduli)
    result = 0
    for ci, ni in zip(ciphertexts, moduli):
        Ni = N // ni
        yi = int(gmpy2.invert(Ni, ni))
        result += ci * Ni * yi
    result %= N
    # Take e-th root
    m, exact = gmpy2.iroot(result, e)
    assert exact
    return int(m)

Bleichenbacher's Attack (PKCS#1 v1.5 Padding Oracle)

Adaptive chosen-ciphertext attack against PKCS#1 v1.5 padding. The oracle tells whether decrypted plaintext has valid 0x00 0x02 padding. Requires ~1 million queries to decrypt.

  • Multiply ciphertext by s^e mod n to get (m*s)^e mod n
  • Query oracle to check if m*s mod n starts with 0x00 0x02
  • Narrow down range of m iteratively

Pollard's Rho

import math
import random

def pollard_rho(n):
    if n % 2 == 0:
        return 2
    x = random.randint(2, n - 1)
    y = x
    c = random.randint(1, n - 1)
    d = 1
    while d == 1:
        x = (x * x + c) % n
        y = (y * y + c) % n
        y = (y * y + c) % n
        d = math.gcd(abs(x - y), n)
    return d if d != n else None

Pollard's p-1

Works when p-1 has only small factors (B-smooth).

import math

def pollard_p_minus_1(n, B=100000):
    a = 2
    for j in range(2, B + 1):
        a = pow(a, j, n)
    d = math.gcd(a - 1, n)
    if 1 < d < n:
        return d
    return None

Quadratic Sieve (Concepts)

  • Factor base: small primes p where n is a quadratic residue mod p
  • Sieve: find values of x^2 - n that factor completely over the factor base
  • Linear algebra: find subset whose product is a perfect square
  • Result: x^2 ≡ y^2 (mod n) → gcd(x-y, n) gives factor
  • Complexity: sub-exponential L(1/2, 1)

RSA Padding Schemes

PKCS#1 v1.5

# Padding format (encryption):
# 0x00 || 0x02 || [random non-zero bytes] || 0x00 || [message]

# Padding format (signature):
# 0x00 || 0x01 || [0xFF bytes] || 0x00 || [DigestInfo || hash]

Vulnerability: Bleichenbacher padding oracle. Also, for signatures with e=3, can forge by constructing valid-looking padding (Bleichenbacher '06 signature forgery).

OAEP (Optimal Asymmetric Encryption Padding)

  • Uses two hash function calls (mask generation)
  • Provably secure in random oracle model
  • Structure: m || 0...0 || 0x01 XOR with mask from random seed
  • Always use OAEP for RSA encryption in practice

Diffie-Hellman Key Exchange

The Math

StepAliceBob
Public paramsPrime p, generator g
Private keya (random)b (random)
Public keyA = g^a mod pB = g^b mod p
Shared secrets = B^a mod ps = A^b mod p

Both compute s = g^(ab) mod p.

Man-in-the-Middle (MITM)

DH alone provides no authentication. Attacker intercepts and establishes separate keys with each party. Fix: authenticate with signatures or certificates.

Small Subgroup Attack

If attacker sends g' = g^((p-1)/q) where q is a small factor of p-1, the shared secret is confined to a small subgroup. Allows brute-force recovery of private key mod q.

Mitigation: Use safe primes (p = 2q + 1), verify received values are in [2, p-2], or use elliptic curve DH.

Elliptic Curve Cryptography (ECC)

Curve Equation

Short Weierstrass form: y² = x³ + ax + b (mod p)

The set of points on the curve plus the point at infinity forms an abelian group.

Point Addition

# Point addition on y^2 = x^3 + ax + b mod p
def point_add(P, Q, a, p):
    if P is None: return Q
    if Q is None: return P
    x1, y1 = P
    x2, y2 = Q

    if x1 == x2 and y1 != y2:
        return None  # Point at infinity

    if P == Q:
        # Point doubling
        lam = (3 * x1 * x1 + a) * pow(2 * y1, -1, p) % p
    else:
        lam = (y2 - y1) * pow(x2 - x1, -1, p) % p

    x3 = (lam * lam - x1 - x2) % p
    y3 = (lam * (x1 - x3) - y1) % p
    return (x3, y3)

def scalar_mult(k, P, a, p):
    result = None
    addend = P
    while k:
        if k & 1:
            result = point_add(result, addend, a, p)
        addend = point_add(addend, addend, a, p)
        k >>= 1
    return result

ECDH (Elliptic Curve Diffie-Hellman)

# Public params: curve E, base point G, order n
# Alice: private a, public A = a*G
# Bob:   private b, public B = b*G
# Shared: S = a*B = b*A = (a*b)*G

ECDSA (Elliptic Curve Digital Signature Algorithm)

# Sign(message, private_key d):
#   k = random nonce in [1, n-1]
#   R = k*G, r = R.x mod n
#   s = k^(-1) * (hash(m) + r*d) mod n
#   signature = (r, s)

# Verify(message, signature (r,s), public_key Q):
#   w = s^(-1) mod n
#   u1 = hash(m) * w mod n
#   u2 = r * w mod n
#   P = u1*G + u2*Q
#   valid if P.x mod n == r

Invalid Curve Attack

If implementation doesn't validate that received points are on the curve, attacker sends points on a weaker curve with small-order subgroup. Recovers private key via CRT after collecting enough relations.

DSA / ECDSA Nonce Reuse

Sony PS3 hack (fail0verflow, 2010): Sony used the same nonce k for every ECDSA signature.

# If same k used for two signatures (r1=r2=r, s1, s2) on messages m1, m2:
# s1 = k^(-1) * (h1 + r*d) mod n
# s2 = k^(-1) * (h2 + r*d) mod n
# s1 - s2 = k^(-1) * (h1 - h2) mod n
# k = (h1 - h2) * (s1 - s2)^(-1) mod n
# d = (s1*k - h1) * r^(-1) mod n

def recover_key_from_nonce_reuse(h1, h2, s1, s2, r, n):
    ds = (s1 - s2) % n
    dh = (h1 - h2) % n
    k = (dh * pow(ds, -1, n)) % n
    d = ((s1 * k - h1) * pow(r, -1, n)) % n
    return d, k

ElGamal Encryption

# Key Generation: prime p, generator g, private x, public h = g^x mod p
# Encrypt(m): random k, c1 = g^k mod p, c2 = m * h^k mod p
# Decrypt(c1, c2): s = c1^x mod p, m = c2 * s^(-1) mod p

def elgamal_encrypt(p, g, h, m):
    import random
    k = random.randint(2, p - 2)
    c1 = pow(g, k, p)
    c2 = (m * pow(h, k, p)) % p
    return c1, c2

def elgamal_decrypt(p, x, c1, c2):
    s = pow(c1, x, p)
    m = (c2 * pow(s, -1, p)) % p
    return m

import gmpy2
from gmpy2 import mpz
import random

def generate_rsa_keypair(bits=1024):
    # Generate two random primes
    state = gmpy2.random_state(random.randint(1, 2**32))
    p = gmpy2.next_prime(gmpy2.mpz_random(state, mpz(2)**bits))
    q = gmpy2.next_prime(gmpy2.mpz_random(state, mpz(2)**bits))

    n = p * q
    phi = (p - 1) * (q - 1)
    e = mpz(65537)

    assert gmpy2.gcd(e, phi) == 1, "e and phi not coprime"

    d = gmpy2.invert(e, phi)

    # Verify: e*d ≡ 1 (mod phi)
    assert (e * d) % phi == 1

    print(f"p = {p}")
    print(f"q = {q}")
    print(f"n = {n}")
    print(f"e = {e}")
    print(f"d = {d}")
    print(f"Bits of n: {n.bit_length()}")

    return (n, e), (n, d), (p, q)

import math
import random
import gmpy2

# Challenge: factor these moduli
challenges = [
    77,            # trivial
    323,           # 17 * 19
    1000000007 * 1000000009,  # product of known primes

def trial_division(n, limit=10**6):
    if n % 2 == 0:
        return 2
    for i in range(3, min(limit, int(math.isqrt(n)) + 1), 2):
        if n % i == 0:
            return i
    return None

def pollard_rho(n):
    if n % 2 == 0:
        return 2
    x = random.randint(2, n - 1)
    y = x
    c = random.randint(1, n - 1)
    d = 1
    while d == 1:
        x = (x * x + c) % n
        y = (y * y + c) % n
        y = (y * y + c) % n
        d = math.gcd(abs(x - y), n)
    return d if d != n else None

for n in challenges:
    print(f"\nn = {n} ({n.bit_length() if isinstance(n, int) else int(n).bit_length()} bits)")

    if p:
        print(f"  Trial division: {p} * {n // p}")
        continue

    # Try Pollard's rho
    for _ in range(10):
        p = pollard_rho(int(n))
        if p and p != n:
            print(f"  Pollard's rho: {p} * {n // p}")
            break
    else:
        print("  Failed to factor (try larger methods)")

# Wiener's Attack
def continued_fraction(num, den):
    cf = []
    while den:
        q = num // den
        cf.append(q)
        num, den = den, num - q * den
    return cf

def convergents(cf):
    h_prev, h_curr = 0, 1
    k_prev, k_curr = 1, 0
    result = []
    for a in cf:
        h_prev, h_curr = h_curr, a * h_curr + h_prev
        k_prev, k_curr = k_curr, a * k_curr + k_prev
        result.append((h_curr, k_curr))
    return result

def wiener_attack(e, n):
    cf = continued_fraction(e, n)
    for k, d in convergents(cf):
        if k == 0 or d == 0:
            continue
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        # Check: n - phi + 1 = p + q, and p*q = n
        s = n - phi + 1  # p + q
        discriminant = s * s - 4 * n
        if discriminant < 0:
            continue
        sqrt_disc = gmpy2.isqrt(discriminant)
        if sqrt_disc * sqrt_disc == discriminant:
            p = (s + sqrt_disc) // 2
            q = (s - sqrt_disc) // 2
            if p * q == n:
                return int(d)
    return None

recovered_d = wiener_attack(e, n)
print(f"\nRecovered d: {recovered_d}")
print(f"Actual d:    {real_d}")
print(f"Match: {recovered_d == real_d}")

# Chinese Remainder Theorem
def crt(remainders, moduli):
    N = reduce(lambda a, b: a * b, moduli)
    result = 0
    for ri, ni in zip(remainders, moduli):
        Ni = N // ni
        yi = int(gmpy2.invert(Ni, ni))
        result += ri * Ni * yi
    return result % N

def forge_signature(message, key_size_bytes=256):

    block = prefix + b'\x00' * (key_size_bytes - len(prefix))

# Batch GCD (efficient for many keys)
def batch_gcd(moduli):
    """O(n log n) batch GCD - finds shared factors across many keys"""
    n = len(moduli)
    # Product tree
    prods = list(moduli)
    while len(prods) > 1:
        new_prods = []
        for i in range(0, len(prods), 2):
            if i + 1 < len(prods):
                new_prods.append(prods[i] * prods[i+1])
            else:
                new_prods.append(prods[i])
        prods = new_prods

    # Remainder tree
    total_prod = prods[0]
    remainders = [total_prod % (ni * ni) for ni in moduli]
    gcds = [gcd(remainders[i] // moduli[i], moduli[i]) for i in range(n)]
    return gcds

import gmpy2

def wiener(e, n):
    # Continued fraction expansion of e/n
    cf = []
    num, den = e, n
    while den:
        q = num // den
        cf.append(q)
        num, den = den, num - q * den

    # Test convergents
    h_prev, h_curr = 0, 1
    k_prev, k_curr = 1, 0
    for a in cf:
        h_prev, h_curr = h_curr, a * h_curr + h_prev
        k_prev, k_curr = k_curr, a * k_curr + k_prev
        k, d = h_curr, k_curr

        if k == 0:
            continue
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        # Verify: x^2 - (n - phi + 1)x + n = 0 has integer roots
        b_val = n - phi + 1
        disc = b_val * b_val - 4 * n
        if disc < 0:
            continue
        sqrt_disc = gmpy2.isqrt(disc)
        if sqrt_disc * sqrt_disc == disc:
            return int(d)
    return None

import gmpy2
from functools import reduce

def crt(remainders, moduli):
    N = reduce(lambda a, b: a * b, moduli)
    result = 0
    for ri, ni in zip(remainders, moduli):
        Ni = N // ni
        yi = int(gmpy2.invert(Ni, ni))
        result = (result + ri * Ni * yi) % N
    return result

Challenge 7: Multi-prime RSA (Medium)

Scenario: n is a product of many small primes instead of two large ones.

# Given:
n = 0x...  # product of multiple primes

# Solution: Factor n (easier when it has many small-ish primes)
import gmpy2
from math import gcd
from functools import reduce

# Method 1: Pollard's rho repeatedly
def factor_all(n):
    factors = []
    while n > 1:
        if gmpy2.is_prime(n):
            factors.append(int(n))
            break
        # Try Pollard's rho
        d = pollard_rho(int(n))
        if d is None:
            # Try p-1
            d = pollard_p_minus_1(int(n))
        if d is None:
            break
        factors.append(d)
        n = n // d
    return factors

def pollard_rho(n):
    import random
    if n % 2 == 0: return 2
    for _ in range(50):
        x = random.randint(2, n-1)
        y = x
        c = random.randint(1, n-1)
        d = 1
        while d == 1:
            x = (x*x + c) % n
            y = (y*y + c) % n
            y = (y*y + c) % n
            d = gcd(abs(x-y), n)
        if d != n:
            return d
    return None

def pollard_p_minus_1(n, B=100000):
    a = 2
    for j in range(2, B+1):
        a = pow(a, j, n)
    d = gcd(a-1, n)
    if 1 < d < n:
        return d
    return None

# Once factored:
def decrypt_multiprime(c, e, n, factors):
    # Use Carmichael's lambda for multi-prime
    def lcm(a, b): return a * b // gcd(a, b)
    lam = reduce(lcm, [f - 1 for f in factors])
    d = int(gmpy2.invert(e, lam))
    m = pow(c, d, n)
    return m.to_bytes((m.bit_length() + 7) // 8, 'big')

factors = factor_all(n)
print(f"Factors: {factors}")
print(f"Flag: {decrypt_multiprime(c, e, n, factors)}")

Challenge 9: RSA LSB Oracle (Hard)

Scenario: Oracle reveals the least significant bit of decrypted ciphertext.

# RSA LSB Oracle Attack
# Oracle tells us if m is even or odd after decryption
# We multiply ciphertext by 2^e to double the plaintext mod n

import gmpy2
from decimal import Decimal, getcontext

def lsb_oracle(c, d, n):
    """Simulated oracle: returns LSB of decrypted message"""
    m = pow(c, d, n)
    return m & 1

def lsb_oracle_attack(n, e, c, oracle_func, d_for_sim):
    """Recover plaintext using LSB oracle"""
    getcontext().prec = n.bit_length() + 100

    # Bounds for m: [lower, upper] = [0, n]
    lower = Decimal(0)
    upper = Decimal(n)
    multiplier = pow(2, e, n)  # Encryption of 2

    c_prime = c
    num_bits = n.bit_length()

    for i in range(num_bits):
        c_prime = (c_prime * multiplier) % n
        # Oracle on c' = c * 2^(e*(i+1)) mod n
        # This corresponds to plaintext 2^(i+1) * m mod n
        bit = oracle_func(c_prime, d_for_sim, n)

        if bit == 1:
            # 2^(i+1) * m mod n is odd → m is in upper half of current range
            lower = (lower + upper) / 2
        else:
            # 2^(i+1) * m mod n is even → m is in lower half
            upper = (lower + upper) / 2

        if i % 100 == 0:
            print(f"  Bit {i}/{num_bits}...")

    # m should be close to upper (or lower)
    return int(upper)

Challenge 10: Coppersmith Short Pad Attack (Hard)

Scenario: Same message with different short random padding, encrypted with e=3.

# Coppersmith's Short Pad Attack
# m1 = M || r1 (M with random padding r1)
# m2 = M || r2 (M with random padding r2)
# Both encrypted with same (n, e=3)
# If padding is short enough, we can use Franklin-Reiter after finding the difference

# This requires Sage for Coppersmith's method. Python-only approximation:

import gmpy2

# Given:
n = 0x...
e = 3
c1 = 0x...  # encrypt(M || pad1)
c2 = 0x...  # encrypt(M || pad2)
pad_bits = 16  # known padding length

# Step 1: Find the padding difference using resultant/GCD
# In Sage:
# PRx. = PolynomialRing(Zmod(n))
# PRxy. = PolynomialRing(PRx)
# f1 = (x + y)^e - c1  # treat pad1 as y
# f2 = x^e - c2         # ... simplified model
# Use resultant to eliminate one variable

# Step 2: Once difference d = r1 - r2 is found, apply Franklin-Reiter
def franklin_reiter_short_pad(c1, c2, diff, e, n):
    """
    After finding diff = pad1 - pad2, use Franklin-Reiter:
    m2 = m1 + diff (mod n)
    """
    # For e=3: polynomial GCD approach
    # f1(x) = x^3 - c1
    # f2(x) = (x + diff)^3 - c2
    b = diff
    numerator = (-b * (c2 + 2*c1 + b**3)) % n
    denominator = (c2 - c1 + 2 * b**3) % n
    m1 = (numerator * int(gmpy2.invert(denominator, n))) % n
    return m1
