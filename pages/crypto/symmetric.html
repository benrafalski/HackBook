AES (Advanced Encryption Standard)

Rijndael algorithm, selected by NIST in 2001 to replace DES.

Key SizeRoundsBlock Size
128 bits (AES-128)10128 bits (16 bytes)
192 bits (AES-192)12128 bits (16 bytes)
256 bits (AES-256)14128 bits (16 bytes)

Round Operations (high-level)

  1. SubBytes — Non-linear S-box substitution (confusion)
  2. ShiftRows — Cyclic left shift of rows in state matrix
  3. MixColumns — Matrix multiplication in GF(2⁸) (diffusion) — skipped in final round
  4. AddRoundKey — XOR state with round key from key schedule

Security: No practical attacks on full AES. Best known: biclique attack on AES-128 reduces security to ~126.1 bits (theoretical).

Sweet32: Birthday attack on 64-bit block ciphers. After 2³² blocks (~32 GB), collision probability is high → plaintext recovery in CBC mode.

Block Cipher Modes of Operation

ECB (Electronic Codebook)

Each block encrypted independently with the same key.

  • The Penguin Problem: Identical plaintext blocks → identical ciphertext blocks → patterns leak
  • Never use for data larger than one block
  • Parallelizable (both encrypt/decrypt)
# ECB mode — same plaintext block = same ciphertext block
from Crypto.Cipher import AES
key = b'YELLOW SUBMARINE'  # 16 bytes
cipher = AES.new(key, AES.MODE_ECB)
# These produce IDENTICAL ciphertext:
c1 = cipher.encrypt(b'A' * 16)
c2 = cipher.encrypt(b'A' * 16)
assert c1 == c2  # Pattern leakage!

CBC (Cipher Block Chaining)

Each plaintext block XORed with previous ciphertext block before encryption. First block uses IV.

  • C_i = E_K(P_i ⊕ C_{i-1}), where C_0 = IV
  • IV must be unpredictable (random) for CPA security
  • Encryption is sequential; decryption is parallelizable
  • Bit errors in ciphertext corrupt current block + flip corresponding bit in next block

CTR (Counter Mode)

Turns block cipher into stream cipher. Encrypts nonce||counter, XORs result with plaintext.

  • Keystream_i = E_K(Nonce || Counter_i)
  • C_i = P_i ⊕ Keystream_i
  • Fully parallelizable, random access to any block
  • Critical: Never reuse (key, nonce) pair — leaks XOR of plaintexts

OFB (Output Feedback)

Keystream generated by repeatedly encrypting the IV. XOR keystream with plaintext.

  • O_i = E_K(O_{i-1}), O_0 = IV
  • No error propagation, but nonce reuse is fatal

CFB (Cipher Feedback)

Previous ciphertext encrypted to produce keystream, then XORed with plaintext.

  • C_i = P_i ⊕ E_K(C_{i-1})
  • Self-synchronizing — recovers from lost ciphertext blocks

GCM (Galois/Counter Mode)

CTR mode + GHASH authentication. Provides both confidentiality and integrity (AEAD).

  • Produces ciphertext + authentication tag
  • Nonce should be 96 bits (12 bytes) for best performance
  • Nonce reuse in GCM: Leaks authentication key H, allowing forgery of arbitrary messages
  • Standard for TLS 1.3

ECB Mode Vulnerabilities

Pattern Leakage

Since E_K(P) is deterministic, repeated plaintext blocks produce repeated ciphertext blocks. Visual example: encrypting a bitmap image in ECB mode preserves the image outline (the "ECB penguin").

Block-at-a-Time (Byte-at-a-Time) Oracle Attack

If an oracle encrypts attacker_input || secret in ECB mode:

  1. Control alignment so target byte is the last byte of a block
  2. Brute-force the unknown byte (256 guesses) by comparing ciphertext blocks
  3. Repeat shifting one byte at a time to recover entire secret
# Byte-at-a-time ECB oracle attack (conceptual)
def ecb_oracle(plaintext):
    """Server encrypts: plaintext || SECRET in ECB mode"""
    return AES_ECB_encrypt(plaintext + SECRET, key)

def attack():
    block_size = 16
    known = b''
    for i in range(len(SECRET)):
        # Align so next unknown byte is at end of a block
        padding = b'A' * (block_size - 1 - (i % block_size))
        target_block = i // block_size
        target_ct = ecb_oracle(padding)[target_block*16:(target_block+1)*16]
        # Brute force the byte
        for byte in range(256):
            guess = padding + known + bytes([byte])
            if ecb_oracle(guess)[target_block*16:(target_block+1)*16] == target_ct:
                known += bytes([byte])
                break
    return known

CBC Mode Attacks

IV Requirements

  • IV must be unpredictable to an attacker (CPA security)
  • Reusing IV with same key leaks whether first blocks are identical
  • Using IV = 0 is a common misconfiguration

CBC Bit-Flipping Attack

Decryption: P_i = D_K(C_i) ⊕ C_{i-1}. Flipping bit j in C_{i-1} flips bit j in P_i (at cost of corrupting block i-1).

# CBC bit-flip: change P[i] by modifying C[i-1]
# To change byte at position pos in block i from old_val to new_val:
# Flip the corresponding byte in the previous ciphertext block
ct = bytearray(ciphertext)
block_offset = (target_block - 1) * 16 + byte_position
ct[block_offset] ^= ord(old_char) ^ ord(new_char)
# When decrypted, block i will have new_char at that position
# (block i-1 will be garbled)

Padding Oracle Attack (Vaudenay)

If a server reveals whether decrypted ciphertext has valid padding (e.g., different error for "invalid padding" vs "invalid data"), an attacker can decrypt any ciphertext without the key.

PKCS#7 Padding Recap

Pad with N bytes of value N: \x01, \x02\x02, \x03\x03\x03, ... \x10×16

Attack Walkthrough (Last Byte)

  1. Target: decrypt block C_i. We control C'_{i-1} (modified previous block).
  2. Decryption produces: P_i = D_K(C_i) ⊕ C'_{i-1}
  3. For valid \x01 padding, last byte of P_i must equal 0x01
  4. Try all 256 values for last byte of C'_{i-1} until server says "valid padding"
  5. When valid: D_K(C_i)[15] ⊕ C'_{i-1}[15] = 0x01
  6. Therefore: D_K(C_i)[15] = 0x01 ⊕ C'_{i-1}[15]
  7. Original plaintext byte: P_i[15] = D_K(C_i)[15] ⊕ C_{i-1}[15]

Extending to All Bytes

To get byte at position (16 - n):

  1. Set already-known suffix bytes of C'_{i-1} so they decrypt to padding value n
  2. Brute-force byte (16 - n) of C'_{i-1} until server reports valid padding (0x0n repeated n times)
  3. Recover intermediate value, compute original plaintext byte

Complexity: 256 × 16 = 4096 oracle queries per block (worst case).

def padding_oracle_attack(ciphertext, oracle, block_size=16):
    """
    oracle(ct) -> True if padding is valid, False otherwise
    """
    blocks = [ciphertext[i:i+block_size] for i in range(0, len(ciphertext), block_size)]
    plaintext = b''

    for block_idx in range(1, len(blocks)):
        prev_block = bytearray(blocks[block_idx - 1])
        intermediate = bytearray(block_size)

        for byte_pos in range(block_size - 1, -1, -1):
            pad_val = block_size - byte_pos  # Target padding value

            # Set already-known bytes to produce correct padding
            crafted = bytearray(block_size)
            for k in range(byte_pos + 1, block_size):
                crafted[k] = intermediate[k] ^ pad_val

            # Brute-force current byte
            for guess in range(256):
                crafted[byte_pos] = guess
                test_ct = bytes(crafted) + blocks[block_idx]
                if oracle(test_ct):
                    # Handle false positive for second-to-last byte
                    if byte_pos == block_size - 1:
                        crafted[byte_pos - 1] ^= 1
                        if not oracle(bytes(crafted) + blocks[block_idx]):
                            continue
                    intermediate[byte_pos] = guess ^ pad_val
                    break

        # Recover plaintext: P = intermediate XOR original prev block
        for i in range(block_size):
            plaintext += bytes([intermediate[i] ^ prev_block[i]])

    return plaintext

CTR Mode: Nonce Reuse

If same (key, nonce) encrypts two messages:

  • C1 = P1 ⊕ Keystream
  • C2 = P2 ⊕ Keystream
  • C1 ⊕ C2 = P1 ⊕ P2 → XOR of plaintexts (crib dragging recovers both)
# CTR nonce reuse — recover XOR of plaintexts
c1 = bytes.fromhex("aabbcc...")
c2 = bytes.fromhex("ddeeff...")
xor_plaintexts = bytes(a ^ b for a, b in zip(c1, c2))
# Now use crib dragging: guess words in P1, XOR with xor_plaintexts to see if P2 is readable

# PKCS#7 implementation
def pkcs7_pad(data, block_size=16):
    pad_len = block_size - (len(data) % block_size)
    return data + bytes([pad_len] * pad_len)

def pkcs7_unpad(data):
    pad_len = data[-1]
    if pad_len == 0 or pad_len > 16:
        raise ValueError("Invalid padding")
    if data[-pad_len:] != bytes([pad_len] * pad_len):
        raise ValueError("Invalid padding")
    return data[:-pad_len]

Stream Ciphers

RC4

  • Variable key length (40–2048 bits), no IV (must be prepended to key)
  • Biases: Second byte biased toward 0; initial keystream bytes correlate with key
  • Broken in practice: WEP attack, RC4 NOMORE attack on TLS
  • Drop first 256/768/3072 bytes as mitigation (RC4-drop)
  • Never use RC4 in new designs

ChaCha20

  • 256-bit key, 96-bit nonce, 32-bit counter
  • 20 rounds of quarter-round operations (ARX: Add, Rotate, XOR)
  • Designed by Daniel Bernstein as variant of Salsa20
  • Used in TLS 1.3 (ChaCha20-Poly1305), WireGuard, SSH
  • Faster than AES on platforms without AES-NI

Key Derivation Functions (KDFs)

Transform passwords/low-entropy inputs into cryptographic keys. Must be slow to resist brute-force.

AES-GCM Authentication

GCM combines CTR-mode encryption with GHASH (polynomial hash over GF(2¹²⁸)).

  • Inputs: Key, Nonce (12 bytes ideal), Plaintext, Associated Data (AAD)
  • Outputs: Ciphertext, Tag (16 bytes)
  • Tag authenticates both ciphertext AND AAD (e.g., headers)
  • Nonce reuse: Recovers H (GHASH key) → forge tags for arbitrary messages
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes

key = get_random_bytes(32)  # AES-256
nonce = get_random_bytes(12)
header = b"authenticated but not encrypted"

cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
cipher.update(header)  # AAD
ciphertext, tag = cipher.encrypt_and_digest(plaintext)

# Decryption + verification
cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
cipher.update(header)
plaintext = cipher.decrypt_and_verify(ciphertext, tag)  # Raises ValueError if tampered

Easy

Objective: Detect ECB mode by identifying repeated ciphertext blocks. Simulate the "penguin problem" with structured data.

from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes
import collections

key = get_random_bytes(16)

# Simulate structured data (like an image with large uniform regions)
# 100 blocks where many are repeated
structured_data = b'\x00' * 16 * 30 + b'\xFF' * 16 * 30 + b'\x00' * 16 * 40

# Encrypt in ECB
cipher = AES.new(key, AES.MODE_ECB)
ecb_ct = cipher.encrypt(structured_data)

# Encrypt same data in CBC
iv = get_random_bytes(16)
cipher_cbc = AES.new(key, AES.MODE_CBC, iv=iv)
cbc_ct = cipher_cbc.encrypt(structured_data)

def count_repeated_blocks(data, block_size=16):
    blocks = [data[i:i+block_size] for i in range(0, len(data), block_size)]
    counter = collections.Counter(blocks)
    repeated = sum(count - 1 for count in counter.values() if count > 1)
    return repeated, len(blocks)

ecb_repeated, ecb_total = count_repeated_blocks(ecb_ct)
cbc_repeated, cbc_total = count_repeated_blocks(cbc_ct)

print(f"ECB: {ecb_repeated}/{ecb_total} repeated blocks (PATTERN LEAKAGE!)")
print(f"CBC: {cbc_repeated}/{cbc_total} repeated blocks (looks random)")

# Detection function
def detect_ecb(ciphertext, block_size=16):
    blocks = [ciphertext[i:i+block_size] for i in range(0, len(ciphertext), block_size)]
    unique_blocks = set(blocks)
    if len(unique_blocks) < len(blocks):
        return True  # ECB detected
    return False

print(f"\nECB detected in ECB ciphertext: {detect_ecb(ecb_ct)}")
print(f"ECB detected in CBC ciphertext: {detect_ecb(cbc_ct)}")

Lab 3: ECB Cut-and-Paste Attack

Medium

Objective: Exploit ECB's block independence to create a forged "admin" profile by rearranging ciphertext blocks from legitimate encryptions.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

key = get_random_bytes(16)

def profile_for(email):
    """Server-side: create encrypted profile (no & or = in email)"""
    email = email.replace('&', '').replace('=', '')
    profile = f"email={email}&uid=10&role=user"
    cipher = AES.new(key, AES.MODE_ECB)
    return cipher.encrypt(pad(profile.encode(), 16))

def decrypt_profile(ct):
    """Server-side: decrypt and parse profile"""
    cipher = AES.new(key, AES.MODE_ECB)
    pt = unpad(cipher.decrypt(ct), 16).decode()
    return dict(item.split('=') for item in pt.split('&'))

# === ATTACK ===
# Goal: create profile with role=admin

# Step 1: Get a block that contains "admin" + padding at a block boundary
# "email=" is 6 bytes. We need "admin" + pkcs7 padding to fill block 2
# Block 1: "email=AAAAAAAAAA"  (6 + 10 = 16)
# Block 2: "admin\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b"  (5 + 11 = 16)
crafted_email = "A" * 10 + "admin" + "\x0b" * 11
ct1 = profile_for(crafted_email)
admin_block = ct1[16:32]  # Block containing "admin" + padding

# Step 2: Get a ciphertext where "role=" ends exactly at a block boundary
# "email=" (6) + email + "&uid=10&role=" (13) = need email of length 13
# Block 1: "email=AAAAAAAAAA" (16)
# Block 2: "AAA&uid=10&role=" (16)
# Block 3: "user" + padding
normal_email = "A" * 13
ct2 = profile_for(normal_email)

# Step 3: Replace block 3 with the admin block
forged = ct2[:32] + admin_block

# Verify
profile = decrypt_profile(forged)
print(f"Forged profile: {profile}")
print(f"Role: {profile['role']}")
assert profile['role'] == 'admin', "Attack failed!"
print("SUCCESS: Elevated to admin!")

Lab 6: CBC Padding Oracle — Decrypt One Byte at a Time

Hard

Objective: Implement a full padding oracle attack to decrypt a CBC ciphertext without knowing the key. The oracle only reveals whether padding is valid.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

# Server setup (secret key)
key = get_random_bytes(16)
iv = get_random_bytes(16)

SECRET = b"Attack at dawn! Send reinforcements."

# Encrypt the secret
cipher = AES.new(key, AES.MODE_CBC, iv=iv)

def pkcs7_pad(data: bytes, block_size: int = 16) -> bytes:
    """Add PKCS#7 padding to reach a multiple of block_size."""
    if block_size < 1 or block_size > 255:
        raise ValueError("Block size must be 1-255")
    pad_len = block_size - (len(data) % block_size)
    # If data is already aligned, add full block of padding
    return data + bytes([pad_len] * pad_len)

def pkcs7_unpad(data: bytes, block_size: int = 16) -> bytes:
    """Remove and validate PKCS#7 padding."""
    if len(data) == 0:
        raise ValueError("Empty data")
    if len(data) % block_size != 0:
        raise ValueError("Data not block-aligned")

    pad_len = data[-1]

    # Validate padding value
    if pad_len == 0 or pad_len > block_size:
        raise ValueError("Invalid padding byte")

    # Validate all padding bytes are consistent
    padding = data[-pad_len:]
    if padding != bytes([pad_len] * pad_len):
        raise ValueError("Invalid padding")

    return data[:-pad_len]

# === GF(2^128) Arithmetic for GHASH ===
# The irreducible polynomial for GCM is: x^128 + x^7 + x^2 + x + 1
# R = 0xE1000000000000000000000000000000 (bit-reflected representation)

def bytes_to_int(b):
    return int.from_bytes(b, 'big')

def int_to_bytes(n):
    return n.to_bytes(16, 'big')

def gf128_mul(x, y):
    """Multiply two elements in GF(2^128) with GCM's polynomial."""
    R = 0xE1000000000000000000000000000000
    z = 0
    v = y
    for i in range(128):
        if (x >> (127 - i)) & 1:
            z ^= v
        if v & 1:
            v = (v >> 1) ^ R
        else:
            v >>= 1
    return z

def ghash(h_int, data_blocks):
    """Compute GHASH over a sequence of 128-bit blocks."""
    y = 0
    for block in data_blocks:
        y = gf128_mul(y ^ bytes_to_int(block), h_int)
    return y

def pad_to_128(data):
    """Pad data to multiple of 16 bytes with zeros."""
    if len(data) % 16 == 0:
        return data
    return data + b'\x00' * (16 - len(data) % 16)

    return result

Two messages were encrypted with the same AES-CTR key and nonce. Recover both plaintexts using crib dragging.

from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes

key = get_random_bytes(16)
nonce = get_random_bytes(8)

msg1 = b"The flag is FLAG{ctr_reuse_bad}"
msg2 = b"Never reuse a nonce with CTR!!"

c1 = AES.new(key, AES.MODE_CTR, nonce=nonce).encrypt(msg1)
c2 = AES.new(key, AES.MODE_CTR, nonce=nonce).encrypt(msg2)

# GIVEN to attacker:
print(f"c1 = {c1.hex()}")
print(f"c2 = {c2.hex()}")
print(f"Hint: One message starts with 'The flag is'")

# YOUR ATTACK:
# 1. XOR c1 and c2 to get p1 XOR p2
# 2. Use the known crib "The flag is" to decrypt corresponding bytes of msg2
# 3. Use discovered msg2 bytes as new cribs to recover more of msg1

xor = bytes(a^b for a,b in zip(c1,c2)) gives P1⊕P2. XOR the known crib with the corresponding xor bytes: bytes(xor[i]^ord(c) for i,c in enumerate("The flag is")) reveals those bytes of msg2. Then use discovered msg2 fragments to recover more of msg1.

Challenge 5: Padding Oracle Decrypt

Hard

A server returns HTTP 200 for valid padding and HTTP 403 for invalid padding. Decrypt the flag without the key.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

key = get_random_bytes(16)
iv = get_random_bytes(16)

FLAG = b"FLAG{padding_oracle_vaudenay_2002}"
cipher = AES.new(key, AES.MODE_CBC, iv=iv)
encrypted_flag = iv + cipher.encrypt(pad(FLAG, 16))

# Server oracle — simulates HTTP response
def server_check(ciphertext: bytes) -> int:
    """Returns 200 if padding valid, 403 if invalid."""
    try:
        test_iv = ciphertext[:16]
        test_ct = ciphertext[16:]
        cipher = AES.new(key, AES.MODE_CBC, iv=test_iv)
        unpad(cipher.decrypt(test_ct), 16)
        return 200
    except:
        return 403

# GIVEN: encrypted_flag (IV prepended)
print(f"Encrypted flag: {encrypted_flag.hex()}")
print(f"Server responds with 200 or 403")
print(f"Test: server_check(encrypted_flag) = {server_check(encrypted_flag)}")

# YOUR ATTACK: Implement padding oracle attack using server_check()
# Recover the flag one byte at a time

For each block, start from the last byte. Craft a 2-block message: [modified_prev_block][target_block]. Iterate byte values 0-255 for the last byte of modified_prev_block until server returns 200. When found: intermediate_byte = guess XOR 0x01. Then set last byte to intermediate XOR 0x02, and brute-force second-to-last byte for valid \x02\x02 padding. Repeat for all 16 bytes, then XOR intermediate with original previous block to get plaintext.

Challenge 6: ECB Block Shuffling

Medium

An admin panel encrypts structured data in ECB. Rearrange ciphertext blocks to escalate your privileges.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes

key = get_random_bytes(16)

def encrypt_record(username, role="user"):
    """Encrypts: 'name=XXXXXXXXXXrole=YYYY' in 16-byte aligned fields"""
    # Fields are padded to exactly 16 bytes each
    name_field = f"name={username}".ljust(16)[:16]
    role_field = f"role={role}".ljust(16)[:16]
    record = (name_field + role_field).encode()
    cipher = AES.new(key, AES.MODE_ECB)
    return cipher.encrypt(record)

def decrypt_record(ct):
    cipher = AES.new(key, AES.MODE_ECB)
    pt = cipher.decrypt(ct).decode()
    fields = {}
    fields['name'] = pt[0:16].split('=')[1].strip()
    fields['role'] = pt[16:32].split('=')[1].strip()
    return fields

# You register as a normal user
your_token = encrypt_record("hackerman", "user")
print(f"Your token: {your_token.hex()}")
print(f"Decoded: {decrypt_record(your_token)}")

# You also register with a specially crafted "username"
# that makes the name field contain "role=admin       "
# HINT: What if your "username" is "role=admin      "?
# Then name_field = "name=role=admin " (16 bytes) — not useful
# But what if you register with username that puts "role=admin" in block position?

Register with a username that when encrypted produces a block containing "role=admin" with proper padding. For example, register as "admin" so the server creates encrypt_record("admin", "admin") — then take block 1 (the role block) from an admin token. Or craft a username so that overflow from the name field creates a valid "role=admin" block that you can substitute into your own token.

Challenge 8: Known Key, Unknown Mode

Easy

You have the key but the server randomly picks ECB or CBC for each encryption. Determine which mode was used for a given ciphertext.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad
from Crypto.Random import get_random_bytes
import random

key = get_random_bytes(16)  # KNOWN to attacker

def encryption_oracle(plaintext: bytes) -> bytes:
    """Encrypts with either ECB or CBC (randomly chosen). Returns ciphertext."""
    if random.choice([True, False]):
        cipher = AES.new(key, AES.MODE_ECB)
        return cipher.encrypt(pad(plaintext, 16))
    else:
        iv = get_random_bytes(16)
        cipher = AES.new(key, AES.MODE_CBC, iv=iv)
        return iv + cipher.encrypt(pad(plaintext, 16))  # IV prepended

# You can choose what plaintext to encrypt
# Determine if ECB or CBC was used for each call

# YOUR APPROACH:
# Method 1: Send repeated blocks and check for repeated ciphertext blocks
# Method 2: Since you have the key, decrypt with ECB and check if it makes sense

Send b'\x00' * 48 (3 identical blocks). If ECB: all ciphertext blocks are identical. If CBC: prepended IV makes the ciphertext 16 bytes longer, and blocks are all different. Check ciphertext length and block repetition.

Challenge 9: CBC IV Recovery from First Block

Medium

A server uses the encryption key as the IV (IV=Key). You can submit ciphertexts and receive error messages containing the decrypted plaintext. Recover the key.

from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes

key = get_random_bytes(16)
iv = key  # VULNERABILITY: IV = Key

def encrypt(plaintext: bytes) -> bytes:
    cipher = AES.new(key, AES.MODE_CBC, iv=iv)
    return cipher.encrypt(plaintext)  # Assumes pre-padded

def decrypt_and_verify(ciphertext: bytes):
    """
    Decrypts and checks content validity.
    Returns plaintext in error message if invalid characters found.
    """
    cipher = AES.new(key, AES.MODE_CBC, iv=iv)
    plaintext = cipher.decrypt(ciphertext)
    if any(b > 127 for b in plaintext):
        # Error message leaks plaintext!
        return {"status": "error", "message": f"Invalid characters in decrypted data", "plaintext": plaintext}
    return {"status": "ok"}

# You have a captured ciphertext (3 blocks):
captured = encrypt(b"A" * 48)
print(f"Captured ciphertext: {captured.hex()}")

# YOUR ATTACK:
# 1. Take first block C1 of captured ciphertext
# 2. Submit crafted ciphertext: C1 || \x00*16 || C1
# 3. From leaked plaintext: P1' XOR P3' = IV = Key

Craft: C1 + b'\x00'*16 + C1. Decryption gives P1'=D(C1)⊕IV and P3'=D(C1)⊕0=D(C1). So P1' ⊕ P3' = IV = Key. The zero block in the middle likely causes high bytes in P2', triggering the error message that leaks all plaintext blocks.

Challenge 10: Multi-Block CBC Manipulation

Hard

A server encrypts JSON data with CBC. Modify the ciphertext to change {"user":"guest","admin":false} to have "admin":true while keeping valid JSON.

from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
from Crypto.Random import get_random_bytes
import json

key = get_random_bytes(16)
iv = get_random_bytes(16)

def create_session(username):
    """Creates encrypted session token."""
    data = json.dumps({"user": username, "admin": False})
    # Resulting JSON: {"user": "guest", "admin": false}
    cipher = AES.new(key, AES.MODE_CBC, iv=iv)
    return iv + cipher.encrypt(pad(data.encode(), 16))

def verify_session(token):
    """Decrypts and parses session. Returns parsed data."""
    token_iv = token[:16]
    ct = token[16:]
    cipher = AES.new(key, AES.MODE_CBC, iv=token_iv)
    try:
        pt = unpad(cipher.decrypt(ct), 16)
        data = json.loads(pt)
        return data
    except Exception as e:
        return {"error": str(e)}

# You get this token as "guest"
token = create_session("guest")
print(f"Token: {token.hex()}")
print(f"Verified: {verify_session(token)}")

# YOUR GOAL: Modify the token so verify_session returns {"admin": true}
# Constraints:
#   - You don't know the key
#   - The decrypted text must be valid JSON
#   - The JSON must have "admin": true (or "admin":true)
#
# HINT: Since IV is prepended and you control it, you can
# bit-flip the IV to modify the FIRST block of plaintext.
# The first block (bytes 0-15) is: {"user": "guest"
# You need to think about what changes to make...

The IV controls the first plaintext block. Plaintext is {"user": "guest", "admin": false}. Block 0 (16 bytes): {"user": "guest". You can XOR bytes in the IV to change block 0 content. Strategy: change the username portion to inject JSON that closes the object early or overwrites the admin field. For example, flip bytes to change "guest" to "a","admin":true} — but you need to ensure the overall JSON is still parseable (even if it has trailing garbage that gets ignored by a lenient parser, or you truncate).
